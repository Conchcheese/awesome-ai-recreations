# 独立复刻执行边界

任务书规定对象、目标、必做效果、交付与验收。输入清单规定原始参考；不同执行者使用同一个完整输入包和同样的附加指示。没有指定的框架、算法、结构、材质、镜头、声音、迭代顺序由执行者决定。

- 只读本包内文件。已有复刻的页面、源码、模型、成片、截图、测量、调参结果和实现记录留在包外。链接不会扩大范围。
- 可用通用编程库、建模与渲染软件、浏览器、编码器及其官方文档。任务书中的限制优先。带有目标对象实现的示例、模板、成品模型、外部参考、生成素材或新增原作片段，需经任务明确许可。若改变共同条件，记录差异并用新输入版本开展比较。
- 使用已有实现时，记录复用范围、来源与许可，标为 `derived`。视觉目标（对齐原作或再设计）单独声明。
- 需要严格隔离时，由组织者仅提供输入包和空输出目录。参与者使用独立的会话与工作目录。工具导出清单可以校验文件，执行环境隔离由组织者负责。

公开交付写明输入版本与摘要、实际模型和执行工具、人工介入、已跑的验收及已知差距。保留有用的最终证据即可。会话、草稿和逐轮尝试由执行者按需本地留存。
