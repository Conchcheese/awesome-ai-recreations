# 通用制作与验收

以下做法供执行者选用。具体交付条件见任务书。

1. **读参考。** 找到影响识别的外轮廓、地标、关节、运动节拍和材质。记下裁切、画幅、相位和视角。遮挡与未提供的角度列为未知，绝对尺寸无标尺时标为估算。
2. **优先解决可见差异。** 可用低细节模型或草图对齐相机、投影与轮廓，然后验证动作端点、联动、零件归属和过渡，再处理材质、灯光及界面。用同机位、同状态、同裁切比较。动画规格、物理模拟和展示设计分别说明。
3. **从实际交付检查。** 打开最终页面或媒体，检查互动、可见效果、时间线、首尾、遮挡和错误。可重复导出时，检验跳转同一帧的结果；视频核对实际编码、帧率、帧数、音轨与完整播放。自动检查和人工观察分别记录。
4. **交付与结论。** 提供启动入口、源码或可编辑源文件、必要依赖及重建命令，附精选关键帧和仍可见的差距。使用可追溯的数值与比较条件。精细测量可选用随包空白规格模板。

来源标记可用 `frame`（读图）、`ref`（资料）、`guess`（估计）和 `calc`（推导）。任何没有原始依据的隐藏结构、拟音、遥测和镜头按推断或创作记录。
