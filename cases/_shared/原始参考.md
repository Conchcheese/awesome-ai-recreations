# 原始参考与权利

以任务 `input.json` 的 `references` 为准。记录给定的原始文件、获取来源、精确路径和 SHA-256。帧图还需按清单的时间点、尺寸、裁切和处理方式获取。来源重新编码或文件摘要变化时，应由组织者确认并冻结新的输入。只取得部分参考时可明确缩小任务范围，再为所有参与者提供同一输入。

原始资料的可见范围决定结论范围。静态产品图可辅助外观判断。真实变形时序、隐藏机构、实测尺寸和物理性能需要相应的原始证据。

原作、角色、影片、摄影及第三方资产保留原权利。来源公开和署名本身不授予再分发权。需本地取得的资料只交给有权使用的人。交付可以附来源清单、授权范围内的内容和自己的渲染结果。
