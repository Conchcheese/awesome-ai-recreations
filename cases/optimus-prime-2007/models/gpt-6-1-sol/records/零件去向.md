# 零件去向与证据等级

172 节点 × 5 姿态的完整追踪可用 `node "series/变形金刚系列/01-擎天柱-电影版/tools/trace-parts.mjs"` 生成到本案例 artifacts/part-trace.json，从当前模型实际导出，包含车辆、25%、50%、75%、人形的世界矩阵。稳定ID对应[装配清单](assembly-catalog.json)；不是两套模型之间的形态变换。矩阵列主序、Y向上，场景尺度为guess。

以下是**本轮装配设计分配**，不能直接视作电影精确内部机构。外观证据支持可见大形，不证明隐藏铰链和每条轨迹。

| 系统与可查询ID | 本轮车辆→人形分配 | 观察/推断边界 |
|---|---|---|
| `window-frame-*` / `chest-door-*` | 驾驶室双窗与门甲→斜置胸窗与下胸甲 | 原片29s支持外观；轴心、轨迹与展翼是推断/设计 |
| `hood-keel` / `forearm-*` / `hood-side-skin-*` | 引擎盖中线移向背侧；侧板随前臂展开 | 长头车体与红蓝火焰可见；此分配不是恢复ILM原拓扑 |
| `radiator-half-*` / `split-bumper-*` | 格栅与保险杠分瓣收拢到躯干侧 | 车头外观可见，内部收纳路径推断 |
| `shoulder-fender-*` / `front-axle-*` | 曲面甲与前轮移到肩背附近 | 肩部ILM80s为外观线索；当前转轴与甲片形状是近似 |
| `hip-gimbal-*` / `thigh-femur-*` / `tibia-*` / `foot-chassis-*` | 后部折叠下肢起立，骨盆与足部就位 | 全身稳定参考不足，尺寸/折叠/藏件均推断 |
| `rear-axle-*` | 后轮站随骨盆升高，保留全部实体轮胎 | 6轮站/10轮胎是本模型实测；人形去向推断 |
| `dorsal-*` / `exhaust-stack-*` | 驾驶室后甲和排气系统→背甲/烟囱 | 可见排气与肩背外观有参考；完整背面未知 |
| `head-cranial-frame` / `head-*` | 头颈在驾驶室上方收纳后抬起 | ILM88s约束盔壳/耳轴/眼眶/面罩外观，收纳机构推断 |
| `palm-*` / `finger-*-joint-*` | 手掌与分指折叠收纳、展开握合 | 指节独立；内部折叠路径为本轮设计 |
| `wrist-blade-track-*` | 前臂轨道滑出，激活能量投影 | 展示设计；投影关闭不属于实体零件消失 |

前后、中段、爆炸研究需分开：爆炸视图沿设计向量外移是装配可视化，不是车辆→人形变形本身；研究滑块允许胸/腿/背等组合展开，不表示电影角色在所选原片拥有完全相同结构。

重建追踪：从仓库根运行 `node "series/变形金刚系列/01-擎天柱-电影版/tools/trace-parts.mjs"`。更换几何或rig后重新导出，再更新差异表与浏览器/离线验收，不手工改矩阵伪造证据。
