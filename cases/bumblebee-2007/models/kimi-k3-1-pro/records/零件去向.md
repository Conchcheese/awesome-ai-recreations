# 零件去向与动作证据

完整 ID、父子归属和 274 个视觉网格见 [assembly-catalog.json](assembly-catalog.json)。以下只列影响双形态识别的主件；所有变形路径都是 **designed / inferred**，不是电影机构复原。

| 车辆端 | 人形端 | 动作设计 |
|---|---|---|
| 左右引擎盖与双黑纹 | 左右上胸甲 | 解锁后向胸口旋转收拢，保留黑纹方向 |
| 前保险杠、格栅、双灯 | 主胸甲与前灯 | 车头整体上移并旋转为胸部正面 |
| 左右车门与侧窗 | 背门翼 | 向外翻转，避免完全遮住肩部轮组 |
| 前轮 | 肩部轮 | 随肩部支架抬升，保持轮面可读 |
| 后轮 | 小腿外侧轮 | 下移至腿部，作为人形后侧层次 |
| 车顶与前风挡 | 背部上甲 | 后移并转至背部，不冒充真实折叠拓扑 |
| 侧裙 | 骨盆侧甲 | 旋转并收拢到腰侧 |
| 后甲板 | 腰部背甲 | 下移形成背部腰部覆盖 |
| 头、四肢、腹部 | 人形对应结构 | 车辆端缩入底盘，人形端分相位展开 |

## 动作关卡

- 0 / 25 / 50 / 75 / 100% 由同一 `stateAt` 计算；自动测试覆盖这五个姿态。
- 主片 3–9 秒保持同一连续镜头覆盖完整变形，没有用切镜跳过中段。
- 15–18 秒的分层展开是研究界面动作，不属于原作变形证据。
- 未进行碰撞检测、零件体积守恒或实体制造验证；中段仍可能出现视觉交叠。
