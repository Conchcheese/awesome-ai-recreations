# 大黄蜂 · 2007 真人电影版｜规格与还原合同

## 输入与目标

- **案例**：`bumblebee-2007`，input version 1。
- **视觉目标 / 实现来源**：`fidelity / independent`。
- **模型署名**：Kimi-K3.1-Pro；执行环境为 WorkBuddy。
- **允许输入**：`local/input-packs/bumblebee-kimi-k3.1-pro/inputs.json` 冻结的 10 个文件，包括两张 TOMY MPM-3 官方产品原图、共同任务和通用方法。
- **禁读范围**：既有大黄蜂/擎天柱实现源码、成品页面、既有测量、截图、动画资产和调参记录。
- **参考限制**：MPM-3 是授权产品外观补充，不是电影原帧。隐藏机构、绝对尺寸、真实碰撞与完整变形拓扑均无原始证据。

## 模型契约与验收

- 坐标：Y 向上，车辆/人形正面朝 +Z；单位是无标尺场景单位。
- 每个模块具有稳定 ID、车辆端变换、人形端变换、局部相位和分层展开向量。
- 纯时间入口：`model.stateAt(transform, explode)`；页面为 `window.__BUMBLEBEE__.setTransform()` / `setTime()`。
- 自动检查：43 个唯一模块、4 轮、5 个姿态、有限且非零的变换、足部地面范围、`t1 → t2 → t1` 世界矩阵一致。
- 浏览器检查：离线 file URL、控件、灰模、移动视口、影片定点与页面错误。
- 不作“无穿模”“真实变形”“电影等同资产”或还原度百分比声明。
