## 3. 唯一输入：喷射相位 p 与 1.8 Hz 心跳

- 时间 t（秒）是唯一输入；相位 `p = frac(t · 1.8)`，p ∈ [0,1)。
- **p = 0 定义为呼气峰值**：t = 0 正落在峰值上（影片第一帧就是满推力喷射）。
- 单脉冲包络（高斯，σ = 0.13）：
  `pulse(p) = exp(−½ · (wrapHalf(p) / 0.13)²)`，`wrapHalf` 把相位折到 [−0.5, 0.5)。
- 外套膜压力：`P(t) = 93 · pulse(p)` kPa。
- 喷口开度：`flap(p) = 0.12 + 0.88 · [smoothstep(−0.13, −0.02, s) · (1 − smoothstep(0.05, 0.18, s))]`，
  s = wrapHalf(p)。峰值全开（1.0），其余时间保留 12% 泄漏，令待机读数不归零（原作待机 6 N）。
- 推力：`T(t) = 2 · P(t)·1000 · A · flap(p)`。峰值恰为 210.945 N。
- 顶部「喷射负载」：`load(t) = pulse(p) · flap(p)`，峰值 100%。
- 其余所有运动（壳瓣呼吸、臂波、虹吸、喙、尾流）都从同一个 p 派生；巡览展开量再从 t 派生。

## 4. 臂卷曲模型（8 臂波 + 拍点姿态）

**关节权重**（前 4 节近直，越靠末端弯得越狠）：

```
bendEnvelope(j) = 0.05 + 0.95 · ((j−3) / 21)^1.35     j = 0..24
Σ bendEnvelope = 10.2189
```

**关节转角**：`θ_j = 26° · bendEnvelope(j) · armCurl(t, i)`。
100% 卷曲时整臂相对转角 = 26° × 10.2189 = **265.7°**；加上臂根初倾 −18°，末端朝向
**247.7°**（卷过竖直、往回勾）。2D 折线：总长 1.000 m；最大外伸半径 0.594 m（第 18 节处），
末端半径 0.410 m（收回 0.18 m），末端在臂根上方 0.186 m → **紧螺旋**成立。

**卷曲指令**（照原作 HUD：喷进/退场约 25%，工作拍约 100%）：

```
armCurl(t, i) = clamp( armBase(t) + armAmp(t) · pulse(frac(p − i/8)) )
```

- `i/8`：相邻臂相位差正好 1/8 周期（0.0694 s）——`armCurl(t + T/8, i+1) ≡ armCurl(t, i)`。
- `armBase / armAmp` 是节拍参数，在拍点前 0.9 s 内平滑过渡（`beatParam`）：

| 节拍 | 0 喷进 | 3.5 光学 | 7.5 外套膜 | 10 R2 臂 | 12.5 虹吸 | 14.5 保持 | 16 喙 | 18.5 拆解 | 21.5 重组 | 24 退场 |
|---|---|---|---|---|---|---|---|---|---|---|
| armBase | 0.22 | 0.95 | 0.94 | 0.74 | 0.94 | 0.84 | 0.94 | 0.50 | 0.70 | 0.20 |
| armAmp | 0.12 | 0.05 | 0.06 | 0.14 | 0.06 | 0.14 | 0.06 | 0.30 | 0.12 | 0.10 |

- 隔离 R2 臂（索引 1）：10–12.5 s 拍点由 `beatAmount('arm', t)` 平滑压到 **0.12**（100% 展开）。
- 3D 装配：`dir = (cos az · cos θ, sin θ, sin az · cos θ)`，az 为臂方位角；8 臂方位
  `az_i = (i + 0.5) · 45°`（正面留出 45° 空档，避免挡住舷窗与喙）。

## 7. 影棚与画面规范

- 背景：冷白蓝渐变（#F6F9FE → #E7F0FB），四周留白大、干净。
- 地面：#E8E0F4 淡蓝地面 + 双层柔和接触影（1.35 m / 0.62 + 0.55 深核心）；极细网格（间距 250 mm，透明度 0.05）。
- 大形：画面里 3 道巨大淡色圆弧 + 2 道虚线圆（半径约 2.1 / 1.45 / 0.85 m，蓝色透明度 0.12–0.2）。
- 顶部一排「+」标记（2 行 × 16 个，宝石蓝，透明度 0.35）。
- 技术标注：原作的英文标注全部中文化（如「玻璃连杆 / 齿轮组」「螺旋末端 16 节」「根部执行器」「喷射涡轮 12 叶片」
  「8 安装座」「泵核自由旋转」），用 1 px 蓝引线连到部件，只在「标注」开关打开或特写拍点出现。
- 光照：三点柔光 + 顶光，白色装甲高光清楚、黑色件有反光，地面淡影不抢主体。

## 12. 宝石蓝版差异：关节细节优先（本版重点）

既有两版的腕足在整机镜头下偏「竹节 / 简化条纹」，关节与滚轮层次不足。本版在不改变 25 s
节拍、结构量（8 腕 / 202 节 / 480 轮 / 1200 铆钉）与 `model.js` 数学契约的前提下，
重写了 `shared/geometry-arm.js`，把每一节做成可近看的机加工装配体：

| 层 | 实现 | 材质 |
|---|---|---|
| 装甲筒 | 车削轮廓一次成型：两端法兰 + 退刀槽 + 两道分模环；筒长 32 mm，留 8 mm 给关节 | 白装甲 |
| 端法兰 | 两道银色法兰 + 中缝刻线 + 8 颗微型紧固螺钉（与法兰合并为单几何批量绘制） | 钢 |
| 检修板 | 深色密封框 + 银色圆角盖板，两层装配缝 | 钢 / 深灰 |
| 铆钉 | 每节 6 颗，两端各 3 颗绕筒分布；总计 1200 颗 | 钢 |
| 丝印 | 4 套 Canvas 程序化贴花（编号 / 型号 / 条码 / 蓝白警示斜纹），按节号循环贴弧面 | 透明贴图 |
| 波纹关节 | 5 波黑色橡胶波纹管，波峰半径 18.4 mm 略大于装甲筒，节间明确露出 | 橡胶 |
| 万向节 | 球头 + 十字轴 + 两侧叉臂 | 深色金属 |
| 液压微缸 | 每节左右各一，活塞杆行程由 `model.hydraulicStroke(t, arm, j)` 驱动（与 HUD 同源） | 深灰 / 钢 |
| 线束 | 每节一段深色软管，串成沿腕走向的连续线缆 | 深灰 |
| 驱动滚轮 | 黑轮胎 + 钢轮辋 + 8 根辐条 + 轮毂 + 中轴 + 宝石蓝端盖，共 6 个 InstancedMesh 叠层；半径 24.8 mm、侧向偏置 22.6 mm | 橡胶 / 钢 / 宝石蓝 |

另外：

- `CAM.arm`（10 s「R2 腕分离」）从整机位推成中近景，成片里能直接看清法兰、辐条与波纹关节；
  其余 9 拍机位与时间点照原作不变（`check.mjs` 有硬断言）。
- 20 s「整机拆解」的总成位移量加倍，外套膜 / 光学 / 虹吸 / 喙 / 臂毂 / 8 腕真正分离成爆炸图。
- 地面去掉满屏方格，只留同心刻度环、径向刻度与十字标记，影棚更接近原作的干净感。
- 地面压深到 `#DFEAF9`，与白装甲拉开一档明度。
- 所有紫色（含 Logo 渐变 `#8f5bf7` / `#5b21b6`）已清除；强调色统一宝石蓝
  `#0F52BA` / `#4A86E8` / `#0A357A` / `#BFD7FA`，与 GLM 版钴蓝 `#1E5FD6` 明确区分。
