## 重建

从仓库根目录安装共用依赖，再查询本版本的构建与检查命令。

```bash
npm ci --prefix shared/mechanical/kit
python3 scripts/catalog.py show v8 --variant glm-5-3-flash
```

离线页面可直接打开。共享工具、离线构建和素材说明见 [机械构建工具](../../../../shared/mechanical/kit/README.md)。执行条件和实现差异见本版验证记录。共同任务见[案例入口](../../README.md)。
