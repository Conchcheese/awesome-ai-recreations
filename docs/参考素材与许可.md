# 输入素材来源与许可

复刻仅使用任务白名单列出的原始媒体，读取文件不等于取得其版权或再分发许可。角色、影视设计、摄影和原作画面保留各自权利，仓库代码许可不覆盖它们。

原作机械章鱼来自 @0x_fokki 的公开演示；其他机械案例使用实物、概念图或上游演示画面，具体范围以任务清单为准，不代表获得完整原作代码或连续动画。部分旧素材未完整归档逐图来源，需如实保留这一限制，不从已实现版本的规格、过程或代码补足。

电影擎天柱的原片、ILM 制作画面与补充产品参考逐文件登记在任务返回的 reference_manifest；按登记的版本、逐帧时间点、尺寸、处理方式和摘要取材。来源重新编码后摘要可能变化，变化时登记新输入版本。公开授权产品图只能提供外观补充，不证明电影隐藏机构。

来源清单用于识别原始文件和权利人，不扩展允许的输入范围。缺失或变化的媒体须重新获取、核验并记录；公开研究用途与署名不等于已取得再分发授权。输入包默认放在 local，完整视频和原始大图不进入 Git。
