# 快速开始

[案例索引](../cases/README.md) · [变形金刚](../series/变形金刚系列/README.md) · [机械复刻](../series/机械复刻系列/README.md)

## 看作品

从案例页选择模型版本，点击互动或巡览。下载仓库后，打开对应版本目录中的 `index.html` 或 `film.html` 可离线体验。本机成片和可编辑工程见[本地工作区](本地工作区.md)。

## 让 Agent 复刻案例

把仓库地址和案例名发给能读取仓库、图像与命令行的 Agent，例如：

```text
https://github.com/topmindspace/awesome-ai-recreations
请独立复刻这个仓库里的 2007 电影版大黄蜂。
```

Agent 按 [AGENTS.md](../AGENTS.md) 准备共同任务包，独立实现并验证。组织同条件比较时，从仓库根目录执行（Python 3.11+）：

```bash
python3 scripts/catalog.py list --tasks
python3 scripts/catalog.py recreate "机械章鱼" --export local/cases/oc8/input-packs/v3 --require-complete
python3 scripts/catalog.py verify local/cases/oc8/input-packs/v3
```

分发同一个核验通过的包和独立输出目录。缺素材时按[取材与校验](共同输入与资源.md#补齐参考与校验)处理。

## 修改或重建现有版本

```bash
python3 scripts/catalog.py show oc8 --variant gpt-6-1-sol
python3 scripts/catalog.py show bumblebee-2007 --variant kimi-k3-1-pro
python3 scripts/workspace.py bumblebee-2007 --variant kimi-k3-1-pro --prepare
```

安装与运行以版本 README 为准。机械系列的 GLM、DeepSeek 和 HY 衍生版共用依赖：

```bash
npm ci --prefix shared/mechanical/kit
npm exec --prefix shared/mechanical/kit -- playwright install chromium
```

已有代码可以重建或改进。若将其用于新的成果，记录为衍生实现并保留来源。完整的仓库布局见[目录图](仓库结构.md)。
