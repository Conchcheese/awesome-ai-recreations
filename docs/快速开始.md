# 快速开始

看作品、让 Agent 独立复刻和重建已有版本是不同操作；本页分别说明。

[返回首页](../README.md) · [机械案例](../series/机械复刻系列/README.md) · [变形金刚案例与角色库](../series/变形金刚系列/README.md) · [文档导航](README.md)

## 看作品

在[首页](../README.md#案例展示)选择案例，点击「互动」或「巡览」即可在浏览器体验；源码和运行说明见系列及版本文档。

下载仓库后，可离线打开对应的互动 HTML 和巡览 HTML。机械系列多用 `*-互动页.html` 和 `*-影片页.html`，变形金刚系列使用 `index.html` 和 `film.html`。MP4 的获取或导出方法见各案例说明。

## 让 Agent 复刻案例

把仓库地址和案例名发给具备仓库、图片和命令行访问能力的 Agent，例如：

```text
https://github.com/topmindspace/awesome-ai-recreations
请复刻这个仓库里的机械章鱼案例。
```

也可以换成「V8 发动机」或「2007 电影版擎天柱」，并补充模型、交付形式等要求。Agent 按根 [AGENTS.md](../AGENTS.md) 定位任务、准备共同输入、独立实现和验证，无需用户查 ID 或选择已有版本。缺少必需素材或环境能力时，它应说明具体限制；不能直接执行代码的聊天工具无法独立交付可运行作品。

默认忠实参考并独立实现。若要重建或修改已有作品，请明确说出版本，例如「运行 HY4 机械章鱼」或「在 DeepSeek 的 V8 版本上改进」。

### 手动查看与导出输入

如需自己检查或给多个 Agent 严格提供同一份输入，在仓库根目录执行（Python 3.11+）：

```bash
python3 scripts/catalog.py list --tasks
python3 scripts/catalog.py recreate "机械章鱼" --export local/input-packs/oc8-v2 --require-complete
python3 scripts/catalog.py verify local/input-packs/oc8-v2
```

从包内 `TASK.md` 开始。缺少原始参考时按[取材与校验说明](共同输入与资源.md#补齐参考与校验)处理。严格隔离时只向执行者提供同一个核验通过的包与各自的空输出目录。

### 获取仓库

```bash
git clone https://github.com/topmindspace/awesome-ai-recreations.git
cd awesome-ai-recreations
```

也可从 [GitHub 仓库](https://github.com/topmindspace/awesome-ai-recreations)选择 Code → Download ZIP，解压后使用。

## 修改或重建现有版本

查询工具需要 Python 3.11+。重建现有作品所需的 Node.js、Blender 和浏览器版本以案例说明为准，重建过程无需模型账号。

从**仓库根目录**查找案例与版本：

```bash
python3 scripts/catalog.py list
python3 scripts/catalog.py show oc8 --variant gpt-6-1-sol
python3 scripts/catalog.py show bumblebee-2007 --variant gpt-6-1-sol
```

查询结果包含成品、源码、规格、参考、工作目录和构建/检查命令。以 GPT-6.1 Sol 章鱼为例，从**仓库根目录**执行：

```bash
cd "series/机械复刻系列/models/gpt-6.1-sol"
npm ci
npx playwright install chromium
node tools/build.mjs all
node tools/check.mjs
node tools/qa.mjs
```

各版安装入口：

| 版本 | 安装位置与方法 | 后续步骤 |
|---|---|---|
| GPT-6.1 Sol / HY4 直出版 | 在各自版本目录执行 `npm ci`、`npx playwright install chromium` | 见 [Sol 说明](../series/机械复刻系列/models/gpt-6.1-sol/README.md)、[HY4 说明](../series/机械复刻系列/models/hy4-direct/README.md) |
| GLM / DeepSeek / HY 衍生版 | 在 GLM 的 `src/kit/` 安装共享依赖，见下方命令 | 见各版本说明或 catalog 查询 |
| GPT-6.1 Sol 大黄蜂 | 在案例目录安装 Node 22+ 的项目依赖、Python 依赖和 Playwright Chromium，并准备 Blender 4.5、FFmpeg | [案例重建与视频导出](../series/变形金刚系列/models/gpt-6.1-sol/bumblebee-2007/README.md#重建) |

共享依赖安装，从**仓库根目录**执行：

```bash
npm ci --prefix "series/机械复刻系列/models/glm-5.3-flash/src/kit"
npm exec --prefix "series/机械复刻系列/models/glm-5.3-flash/src/kit" -- playwright install chromium
```

GLM 构建到 `teardown-out/dist/`；其他版本构建会更新各自的成品 HTML。视频导出另需 Python、FFmpeg / ffprobe，输出默认忽略。

## 常见问题

| 问题 | 处理 |
|---|---|
| GitHub 打开 HTML 只看到代码 | 使用「在线演示」链接，或下载后双击 HTML |
| 找不到 JavaScript 依赖 | 按目标版本安装入口执行 `npm ci` |
| 找不到 Chromium | 在对应依赖目录执行 `npx playwright install chromium` |
| Linux 缺少浏览器系统库 | 在对应依赖目录执行 `npx playwright install --with-deps chromium` |
| 不同电脑画面略有差异 | 字体、GPU 和浏览器可能影响像素；记录运行环境后对照 |
| 导出视频失败 | 检查 FFmpeg / ffprobe 和 Python；对比片还需自行提供有权使用的原视频 |


## 变形金刚与原始参考

擎天柱的 28 秒 Cycles 影片有 Release 下载。大黄蜂各版提供离线巡览和本地成片生成命令。各作品的在线演示、离线 HTML 和成片入口见[系列首页](../series/变形金刚系列/README.md)与[发布说明](../series/变形金刚系列/docs/发布说明.md)。

新复刻先按共同任务准备原始参考。擎天柱任务提供电影片段来源和时间点，大黄蜂任务登记两张 MPM-3 官方产品图。下载后按输入清单核对摘要，已有离线页面可直接打开。

```bash
python3 scripts/catalog.py recreate 擎天柱
python3 scripts/catalog.py recreate 大黄蜂
python3 "series/变形金刚系列/tools/characters.py" list
python3 "series/变形金刚系列/tools/characters.py" show 大黄蜂
python3 "series/变形金刚系列/tools/characters.py" fetch bumblebee-2007
python3 "series/变形金刚系列/tools/characters.py" start bumblebee-2007
```

角色库用于查找来源和研究候选。 `fetch` 获取已登记的直链图片，`start` 创建研究草稿。独立复刻可使用的素材范围以共同任务为准。
