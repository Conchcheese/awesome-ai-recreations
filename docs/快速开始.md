# 快速开始

看作品、让 Agent 独立复刻和重建已有版本是不同操作；本页分别说明。

[返回首页](../README.md) · [机械案例](../series/机械复刻系列/README.md) · [变形金刚案例与角色库](../series/变形金刚系列/README.md) · [文档导航](README.md)

## 看作品

在[首页](../README.md#案例展示)选择案例，点击「互动」或「巡览」即可在浏览器体验；源码和运行说明见系列及版本文档。

下载仓库后，双击 `*-互动页.html` 可离线操作，双击 `*-影片页.html` 自动巡览。影片页是网页；MP4 视频需要另外导出，命令见版本说明。

## 让 Agent 复刻案例

把仓库地址和案例名发给具备仓库、图片和命令行访问能力的 Agent，例如：

```text
https://github.com/topmindspace/awesome-ai-recreations
请复刻这个仓库里的机械章鱼案例。
```

也可以换成「V8 发动机」或「2007 电影版擎天柱」，并补充模型、交付形式等要求。Agent 按根 [AGENTS.md](../AGENTS.md) 定位任务、准备共同输入、独立实现和验证，无需用户查 ID 或选择已有版本。缺少必需素材或环境能力时，它应说明具体限制；不能直接执行代码的聊天工具无法独立交付可运行作品。

默认忠实参考并独立实现。若要重建或修改已有作品，请明确说出版本，例如「运行 HY4 机械章鱼」或「在 DeepSeek 的 V8 版本上改进」。

### 手动查看与导出输入

如需自己检查或给多个 Agent 严格提供同一份输入，在仓库根目录执行（Python 3.10+）：

```bash
python3 scripts/catalog.py list
python3 scripts/catalog.py recreate "机械章鱼" --export local/input-packs/oc8
```

输入包从 `TASK.md` 开始；`inputs.json` 列出文件摘要和缺失媒体，导出目录已存在时需换一个新目录。缺失素材按包内来源清单获取、核验并记录，不能用已有成果截图替代。严格隔离时只向执行者提供同一个完整输入包与独立输出目录；详情见[共同输入与资源](共同输入与资源.md)。

### 获取仓库

```bash
git clone https://github.com/topmindspace/awesome-ai-recreations.git
cd awesome-ai-recreations
```

也可从 [GitHub 仓库](https://github.com/topmindspace/awesome-ai-recreations)选择 Code → Download ZIP，解压后使用。

## 修改或重建现有版本

需要 Node.js 20+；查询工具需要 Python 3.10+。重建现有代码无需模型账号。

从**仓库根目录**查找案例与版本：

```bash
python3 scripts/catalog.py list
python3 scripts/catalog.py show oc8 --variant gpt-6-1-sol
```

查询结果包含成品、源码、规格、参考、工作目录和构建/检查命令。以 GPT-6.1 Sol 章鱼为例，从**仓库根目录**执行：

```bash
cd "series/机械复刻系列/gpt-6.1-sol复刻"
npm ci
npx playwright install chromium
node tools/build.mjs all
node tools/check.mjs
node tools/qa.mjs
```

其他版本的安装入口：

| 版本 | 安装位置与方法 | 后续步骤 |
|---|---|---|
| GPT-6.1 Sol / HY4 直出版 | 在各自版本目录执行 `npm ci`、`npx playwright install chromium` | 见 [Sol 说明](../series/机械复刻系列/gpt-6.1-sol复刻/README.md)、[HY4 说明](../series/机械复刻系列/hunyuan直出版/README.md) |
| GLM / DeepSeek / HY 衍生版 | 在 GLM 的 `src/kit/` 安装共享依赖，见下方命令 | 见各版本说明或 catalog 查询 |

共享依赖安装，从**仓库根目录**执行：

```bash
npm ci --prefix "series/机械复刻系列/glm5.3-flash复刻/src/kit"
npm exec --prefix "series/机械复刻系列/glm5.3-flash复刻/src/kit" -- playwright install chromium
```

GLM 构建到 `teardown-out/dist/`；其他版本构建会更新各自的成品 HTML。视频导出另需 Python、FFmpeg / ffprobe，输出默认忽略。

## 常见问题

| 问题 | 处理 |
|---|---|
| GitHub 打开 HTML 只看到代码 | 使用「在线演示」链接，或下载后双击 HTML |
| 找不到 JavaScript 依赖 | 按目标版本安装入口执行 `npm ci` |
| 找不到 Chromium | 在对应依赖目录执行 `npx playwright install chromium` |
| Linux 缺少浏览器系统库 | 在对应依赖目录执行 `npx playwright install --with-deps chromium` |
| 不同电脑画面略有差异 | 字体、GPU 和浏览器可能影响像素；记录运行环境后对照 |
| 导出视频失败 | 检查 FFmpeg / ffprobe 和 Python；对比片还需自行提供有权使用的原视频 |


## 变形金刚与原始参考

电影版网页可在线运行或离线打开；28 秒 MP4 见系列 README 的 Release 链接。擎天柱任务的电影原帧不随 Git 发布，既有页面无需这些文件即可运行；新复刻按 `tasks/optimus-prime-2007/input.json` 中的来源、时间点和处理记录准备参考，并检查输入包中的缺失项。其他案例的参考是否随仓库提供，以各自任务和输入包为准。

```bash
python3 scripts/catalog.py recreate 擎天柱
python3 "series/变形金刚系列/tools/characters.py" list
python3 "series/变形金刚系列/tools/characters.py" show 大黄蜂
python3 "series/变形金刚系列/tools/characters.py" fetch bumblebee-2007
python3 "series/变形金刚系列/tools/characters.py" start bumblebee-2007
```

角色库是研究草稿。fetch只处理已冻结的直链图片，片段/图证须抽帧登记后才进入视觉复刻；start不会复制擎天柱几何或登记成品。电影母版50秒、渲染剪辑28秒，两个输出用途不同。依赖与Blender安装/导出命令见具体案例README。
