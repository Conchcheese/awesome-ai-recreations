# 对照复刻约定

## 固定共同输入

同一组实验共享完整包、原始媒体字节、任务书、通用资源约定和附加指示。由组织者分发输入版本与摘要，为每位执行者提供独立工作空间。预算、交互机会、外部素材权限若参与比较，也统一约定。

只给文件和指示仍无法证明执行隔离。需要盲测时，隔离环境并记录实际开放范围。发现旧成果曝光、额外参考或人工引导时，公开注明，并按实际条件解释结果。

## 如实记录执行差异

| 记录 | 内容 |
|---|---|
| 输入 | 任务 ID、输入版本、共同摘要、实际可用参考和偏离项 |
| 执行 | 模型署名与证据、执行工具、关键环境、人工介入 |
| 来源 | `independent` 或 `derived`，复用范围及出处 |
| 结果 | 交付物、实际验证、差距与未知 |

模型与工具版本未知时标未知。成本、耗时和通过率仅在范围、测量方法与数据都清楚时记录。执行者自行选择结构、算法和制作顺序；完整提示词、对话、每轮修改及未采用的草稿可选。

## 比较实际交付

看相同画幅、裁切、机位或动作相位，分别评估轮廓与比例、机构与动作、材质、交互、摄影与声音。视觉目标分别标 `fidelity`（对齐参考）或 `reinterpretation`（允许改编）。记录能打开和能重建的产物，注明证据范围和未验事项。历史实现可能有不同参考、资源和迭代条件，适合作品对照；归因到模型能力需有控制条件。

将可复用经验写为通用方法。让经验进入比较条件时，为下一轮冻结新包。单版坐标、几何、参数和结果留在该版成果。
