# 对照复刻约定

目标是在一致的原始参考和目标要求下，观察不同智能体、模型与工具的实现结果，并研究怎样稳定地产出高质量案例。比较应能解释差异，制作经验应能在后续案例中复用。

输入与成果的具体边界、导出命令见[共同输入与资源](共同输入与资源.md)。新复刻只收到输入；已有代码和过程保留在成果档案中供后续审阅、重建。

## 固定共同输入

| 需要固定 | 如何记录 |
|---|---|
| 案例与目标 | 具体角色/产品/年份，fidelity 还原或 reinterpretation 改编 |
| 原始参考 | 明确文件清单、来源、尺寸与摘要；补充参考和未知部分单列 |
| 任务要求 | 双形态、动作、交互、网页/视频输出，以及验收要求 |
| 允许输入 | 独立复刻允许原作、任务方法与第三方库；衍生实现声明读取过的旧成果 |

对照实验若追加参考或改变目标，要记录为输入变化；不能把新增条件下的改进全部归因于模型。只按一致的原始参考与要求开展尝试，不要求所有工具使用同一种技术栈。

## 如实记录执行差异

每个实现记录实际智能体、模型名称与可确认的版本、工具链、主要迭代及人工修改。时间、费用、调用轮次或预算只有实际记录后才能比较，未归档写未知。不用旧成果冒充新的模型调用，不靠相似度或展示铭牌证明模型身份。

同一参考目标是一个案例，模型/实现是其版本。新版本独立保存；读取既有实现或几何时标 derived 并注明来源。研究草稿和参考档案不计入已实现案例。

## 比较实际交付

先匹配参考的相机与姿态，再比较轮廓、比例、关键部件及可见动作。隐藏机构和推测尺寸单列，不用零件数量代替还原质量。

| 观察维度 | 应保留的证据 |
|---|---|
| 造型与材料 | 相同观察条件下的关键视图、近景及尚存差异 |
| 机构与动作 | 起止状态、中段、实体去向；区分原作可见与展示设计 |
| 交互与稳定性 | 实际控件操作、重入、播放/暂停、桌面与小屏检查 |
| 视频与声音 | 实际编码文件、完整播放、转场与字幕、动作音效和听审结果 |
| 可复现性 | 锁文件、准确命令、输入来源与新克隆检查 |

自动检查证明其覆盖的技术条件；视觉还原、听感和艺术质量仍需审看。未运行的检查不写通过，条件不一致的数字不做无说明排名。

## 把结果转为方法

每轮写清“观察到的差异 → 采取的修改 → 复查结果”，再总结哪些步骤可复用、哪些依赖本角色或工具。保留有价值的参考与结论，公开首页不堆任务流水。方法在其他案例复用后，再判断其稳定性和适用范围。

实现步骤见[精细复刻流程](精细复刻流程.md)，新增内容见[贡献指南](../CONTRIBUTING.md)。
