# 精细复刻流程

目标是让“像不像”可讨论、可定位、可迭代。现有机械案例是程序化近似与改编，自动测试通过不代表已忠实还原原作。

多智能体或多模型的新实验先按[对照复刻约定](对照复刻约定.md)固定共同参考与目标，再使用下列流程提高实现与交付质量。

## 先确定两组属性

| 属性 | 选择 | 含义 |
|---|---|---|
| 视觉目标 | `fidelity` / `reinterpretation` | 对齐原作 / 允许设计改编 |
| 实现来源 | `independent` / `derived` | 只看约定参考重写 / 复用已有实现并署名 |

独立性与还原质量分别评价。新对照实验默认独立实现，只看共同输入；用户明确要求读取旧实现时才作为衍生任务。通用步骤不规定某角色的具体参数、机构拓扑或代码架构，各智能体据参考自行求解。

## 阶段 0：冻结输入与验收约定

保存参考来源、获取日期、分辨率、裁切、允许的输入和使用限制。视频取每个事件前后与稳定时刻的帧，不能只取最漂亮的一张。静图无法推断背面或真实物理性能，这些列为未知。

填 `templates/spec.md`：每个参数带数值、单位、依据帧/区域、来源类型和可信度。来源用 `frame`（读图）、`ref`（外部资料）、`guess`（估算）、`calc`（公式推导）；任意世界尺寸若无标尺只能是 `guess`，不能因写成米就称为“真实尺寸”。

先写偏差合同：哪些必须还原，哪些允许改色/中文化/简化。把“机器占画面 60–70%”之类风格建议放在参考不足时使用；原作构图明确时以原作测量为准。

## 阶段 1：轮廓、比例和相机

只用灰模：主躯干、主要关节、八腕轮廓、外壳开合。固定参考画布、裁切和相位，记录主体包围框 `(x,y,w,h)`，坐标归一化到 0–1；标出穹顶顶点、眼中心、腕根、腕尖等至少 6 个可见地标。

先调相机投影（透视/正交、FOV、方位、俯仰、距离），再调物体尺寸。不要用拉长模型补相机错误；不要先加细节掩盖轮廓问题。

交付同尺寸的并排图、50% 透明叠图和差异表。可选的**首轮目标**：主体包围框边缘误差小于画幅 3%，关键地标平均偏移小于对角线 2%，动作事件差小于 0.2 s；这些是项目约定值，尚未在现有案例上达标验证。透视遮挡和原作不确定性应注明；不能为了达数字裁掉不相似部件。

## 阶段 2：机构与动作

将动作拆为驱动输入、联动关系、关节范围与装配约束。章鱼可用 `stateAt(t)` 计算相位、壳瓣角、腕足曲线、隔离/拆解位移；V8 则需要曲轴角、滑块曲柄和点火顺序。共同时间输入不意味着每个机构只有一个物理自由度。

为关节端点闭合、零件间隙、结构计数、运动连续性加独立可推导的断言。模型常数与期望常数简单抄一遍不构成验证。HUD 中设计的压力、功率等标为“模拟值”，只有有出处的测量才称“真实值”。

## 阶段 3：细节和材质

按镜头可见尺度分配预算：先做影响剪影的腕节与轮盘，再做装配层次和线缆，最后做铆钉、丝印、划痕。使用近景裁切对照零件的节距、直径、缝隙和明暗关系；十层装配体或 1200 颗铆钉只是数量，不能独自证明真实感。

材质分开调粗糙度、金属度、法线/倒角与光照。用主机位、外套膜打开、腕足微距三张无 HUD 图看白壳是否糊成一片、黑关节是否丢层次。先对齐光源方向和接触阴影，再调色，不给全机套强调色。

## 阶段 4：HUD 和构图

测量面板边界、留白、标题层级、字号与图表形态。中文化可能改变文字长度，重排要登记偏差。标注线不能指错部位，面板不覆盖关键动作；桌面参考画幅优先，其他尺寸说明支持范围。

原作若有静止镜头，应保持静止；“持续运镜”不是普遍质量标准。绕行时检查相机轨迹是否穿机，转场的速度和加速度是否突然改变；镜头改编单独记录。

## 阶段 5：时间线与逐帧检查

每拍固定代表帧；每次开合、隔离、切镜前后以 0.2 s 步长检查，疑似跳变缩到逐帧。比较相同动作状态，不能把 8.0 s 与尚未开完的 7.95 s 当作等价帧。

确定性检查用 `t1 → t2 → t1` 的状态和截图回放，捕捉累积状态、随机值、时钟和 CSS 动画；只调用两次同一个数学函数不能证明整个页面逐帧一致。跨 GPU 的像素差异另记。

## 阶段 6：交付与结论

交付源码、锁文件、准确命令、最少一张接触表、关键原作对照、实际执行日志摘要和已知偏差。视频另验分辨率、帧率、时长、黑帧、音画同步、音量与首尾衔接；无音乐就写无音乐。

`records` 写三列：观察到的差异 → 本轮修改 → 同机位复查结果。每轮只先处理 3 个影响最大的差异。区分自动测试、人工视觉检查和未验证事项，不发没有定义的“还原度 95%”。
