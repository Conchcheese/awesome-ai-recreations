# 本地工作区

从仓库根目录运行 `python3 scripts/workspace.py` 查看本地目录约定。所有内容均由 Git 忽略。

| 目录 | 找什么 |
|---|---|
| `local/input-packs/` | 已导出的独立复刻包和旧包 |
| `local/projects/<case>/<project>/` | 本地制作项目、素材准备和草稿 |
| `local/references/` | `tasks/<case>/` 存共同原始媒体，`characters/<id>/` 存角色库样例，`versions/` 存各版专用参考，`research/` 存系列取材 |
| `local/runs/<series>/<project>/` | 构建、渲染、逐帧、QA、临时视频 |
| `local/deliveries/<case>/<project>/` | 已选定的本地成片、封面和精选图 |
| `local/runtime/` | 便携工具及历史项目运行资源 |
| `local/archive/` | Git 历史备份、历次迁移、退役项目 |

## 查找或准备一版成果的运行目录

```bash
python3 scripts/workspace.py bumblebee-2007 --variant kimi-k3-1-pro
python3 scripts/workspace.py bumblebee-2007 --variant kimi-k3-1-pro --prepare
```

查询会同时显示项目的 `artifacts` 入口与中心目录。加 `--prepare` 后，工具把已有的 `artifacts` 迁到中心目录，并建立本地相对链接；遇到已有冲突会停止。构建和验收仍按版本 README 运行。Node 依赖按各自锁文件安装在项目目录，各版生产契约从中心目录读取其专用参考，并兼容旧检出位置。

共同任务的输入包维持冻结时的逻辑路径。取材放到 `local/references/tasks/<case>/`，导出时自动按包内路径复制并核对原摘要。旧检出保留的任务内原件也可读取。

历史发布页和运行所需资源由仓库追踪。预览、交付、依赖、原视频与私人资料分别管理，提交边界见[发布与清理](发布与清理.md)。
