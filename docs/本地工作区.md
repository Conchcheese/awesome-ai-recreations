# 本地工作区

本地沿用与 Git 相同的案例和版本 ID。整个 `local/` 由 Git 忽略。

```text
local/
  cases/<case-id>/
    input-packs/             导出并核验的任务包
    references/task/         该任务仅供本地使用的原始媒体
    models/<variant-id>/
      project/              本地专有源码或可编辑工程
      references/           本版专用媒体
      runs/                 构建、渲染、帧缓存、诊断和 QA
      deliveries/           选定成片、封面、可编辑工程入口
      runtime/              仅该版本需要的便携工具与资源
    projects/               封面、对比等案例配套工程
    deliveries/             案例级配套交付
  research/                 角色库下载和系列取材
  runtime/                  跨案例本机运行工具
  archive/                  历史备份和迁移记录
```

## 查找和准备运行目录

从仓库根目录运行：

```bash
python3 scripts/workspace.py 大黄蜂 --variant gpt-6-2-sol
python3 scripts/workspace.py 大黄蜂 --variant kimi-k3-1-pro --prepare
```

查询显示运行目录与交付位置。已登记的版本可用 `--prepare` 将工程的 `artifacts` 接到该版 `runs/`。已有两份产物时停止并保留双方。依赖按版本锁文件安装。可从版本 README 查询运行方式，也可用 `catalog.py show` 查已登记的重建命令。

《擎天柱·余烬信号》和《大黄蜂·午夜回波》均在对应案例下的 `models/gpt-6-2-sol/deliveries/`。这些目录包含成片、精选图与可编辑 Blender 工程入口。
