[文档导航](README.md) · [贡献指南](../CONTRIBUTING.md)

## 提交范围

| 内容 | 处理 |
|---|---|
| 源码、锁文件、任务书、规格、验证摘要 | 提交；记录最终行为、运行命令和限制 |
| 离线 HTML、封面、精选静帧 | 提交 |
| 已登记来源及权利状态、决定公开的精简原始参考图 | 放对应 `tasks/<id>/references/` 并登记摘要；旧来源不完整须标注 |
| 原始长视频、未登记的大图与下载 | 放 `local/` 或 `原视频/`，已忽略 |
| 非公开记录与配置 | 放 `private/`，已忽略 |
| 录制中间片、临时截图、日志、完整导出 | 放 `artifacts/`，已忽略 |
| 依赖、缓存、编辑器文件、密钥 | 已忽略；只提交无真实值的 `.env.example` |
| 视频、音频、GLB/Blend、安装包与压缩包 | 默认忽略；正式交付按具体授权和发布说明另行分发；机械系列已有登记许可的 OGG 样本保留在指定样本目录 |

公开文档不能只依赖被忽略的本地文件。参考素材保留来源与许可；对比片含原作画面和音轨，仓库 MIT 不自动覆盖这些内容。

## 提交前检查

从仓库根目录执行：

```bash
python3 scripts/check_repo.py
python3 -m unittest discover -s tests -v
git diff --check
git status --short
```

行为变化另跑涉及版本的模型检查、浏览器 QA 与视觉对照。仓库检查覆盖目录索引、本地链接及标题锚点、常见敏感文件/凭据、作者绝对路径和大文件；远程链接和素材许可需要另行核对。

`.gitignore` 不影响已经跟踪的文件。清理前检查来源与引用，不使用 `git clean -fdx` 删除本地资料。

## 变形金刚系列补充规则

[系列发布说明](../series/变形金刚系列/发布说明.md)与[公开素材清单](../series/变形金刚系列/publication.json)区分自渲染、CC0与原始版权参考。来源元数据和明确标注的非商用产品研究板可提交；原始大图、影片帧和含原片对照留 local。研究板须有逐图来源、权利归属和未取得再分发许可的明确说明，不能以仓库 MIT 再授权。新增媒体必须逐项登记摘要和权利类别，未登记二进制被发布检查拒绝。67个角色研究档案单列，不计为已完成模型。正式MP4通过Release分发并核对摘要，不解除Git视频忽略规则。

暂存候选后可运行 `python3 scripts/check_clean_checkout.py`，自动导出实际Git索引到隔离目录，检查不携带local/依赖的新副本，并确认严格取材门禁拒绝缺媒体；不访问网络，不修改源工作区。

## 单提交快照发布

仅在维护者明确要求压缩全部历史时：先验证并冻结提交候选，把旧 Git 引用打包到被忽略的本地备份，建立内容一致的无父提交；核对远端旧哈希后用 force-with-lease 更新 main。已有发布标签需同步指向快照，保留 Release 素材及其独立摘要，避免标签继续保留旧历史。历史重写改变提交哈希；已有克隆应重新克隆或由维护者明确对齐，不能直接合并旧 main。远端旧对象、缓存或外部克隆的物理清除不由本仓库保证。

音轨与混音母版、纯音效试听、重编码预览均属于 artifacts，不随 Git 发布。公开的是音效生成方法、事件时间表的生成代码和验收方式，不能把电平通过描述成人工听审通过。

全仓任务层 tasks 只分发共同需求、原始参考及来源元数据。登记前由仓库检查验证路径和摘要；新媒体来源不明时不能冒称已核验许可。原片等不随 Git 分发的媒体放任务的 references/local，导出包留 local；成果代码与过程不混入任务。
