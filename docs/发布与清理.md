# 发布与清理

## 内容去向

| 内容 | 位置与处理 |
|---|---|
| 共同任务、资源规则与已核验的参考清单 | Git 的 `tasks/`；有权分发的必要原始参考随任务 |
| 作品交付、源码、锁文件、运行依赖说明、精选图和验收摘要 | Git 的 `series/`；保持正式 HTML 和 Pages 路径 |
| 合规的正式 MP4、GLB 等大文件 | 明确发布时使用 GitHub Release 或外部存储，登记格式、来源、许可、文件摘要 |
| 原视频、大图、输入包、历史过程和工作草稿 | 按[本地工作区](本地工作区.md)分别保存；共同原始媒体放 `local/references/tasks/` |
| 个人配置、非公开会话、第三方私有资产 | `private/` 或仓库外。凭据使用凭据管理器或环境变量 |
| 依赖、逐帧、临时截图、诊断日志、渲染自检、试听和转换文件 | `artifacts/` 或工具的忽略目录；源码与再生成命令按需提交 |

公开记录以输入出处、可重建交付、实测结论与关键证据为准。完整会话和轮次记录默认按需本地保存。已有公开档案中的必要历史证据可以保留，新增读者通过正式入口查看当前用法。

## 提交前检查

1. 查看 `git status --short` 与候选 diff。优先精确暂存。对已跟踪的本地文件，先移到忽略目录或仅从索引移除，避免误删原件。
2. 跑 [贡献指南](../CONTRIBUTING.md)的检查。暂存快照验证会读取实际索引，在无本机媒体和依赖的目录检查链接、任务、测试和发布清单。
3. 检查密钥、绝对路径、登录痕迹和截图元数据；自动扫描只覆盖常见模式，检查前不输出敏感值。若历史提交曾包含有效凭据，优先吊销，历史清除需单独处理。
4. 核对第三方素材来源和分发权限，模型或媒体变化时实开页面、解码文件、核对帧数与声音。检查通过后正常快进推送。

`.gitignore` 只决定默认追踪范围。检查会拒绝强制暂存的忽略项。清理前确认链接和运行依赖，勿用 `git clean -fdx` 清理工作区。

## 演示与文档链接

仓库文档用相对路径，Pages 演示用项目地址加正式 HTML 的仓库相对路径。未上传的本地视频写生成命令和输出位置，只有可访问产物才提供下载。Pages 部署由 GitHub 设置管理，仓库 CI 负责检查。
