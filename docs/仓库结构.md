# 仓库结构

仓库以**案例 → 模型版本**为唯一主结构。系列页负责导航；共同任务、正式实现和本地交付都按案例 ID 找。

```text
cases/
  <case-id>/
    README.md                案例首页、任务和版本入口
    task/
      brief.md               统一需求、目标、允许资源与验收
      input.json             输入版本、来源、参考路径及 SHA-256
      references/            有权随 Git 分发的共同参考
    models/<variant-id>/
      README.md              使用、重建、执行来源与验收
      index.html / film.html  正式离线交付
      src/、tools/            本版实现与重建工具
      records/、references/  本版的必要证据与专用来源
  _shared/                   输入包允许的通用方法和资源规则
  index.json / inputs.lock.json
series/                      按系列浏览、系列研究和制作说明
shared/mechanical/           既有机械工程共用构建工具与上游快照
site/                        Pages 旧演示地址的兼容记录
docs/、templates/             维护说明与空白模板
scripts/、tests/              索引、任务包、工作区和发布校验
```

一个案例的多次执行或不同模型分别保存。复用上游工具与复用某个实现是不同条件。共用机械构建链服务既有成果重建，独立任务仍由冻结包定义允许的输入。

- **看或重建**：从[案例索引](../cases/README.md)进入对应版本。
- **交给 AI**：从案例的 `task/` 导出完整输入包，给每个 AI 单独的输出目录。
- **找本机成片**：用同样的案例 ID 和版本 ID 进入[本地工作区](本地工作区.md)。
- **维护**：依[贡献指南](../CONTRIBUTING.md)登记，按[发布与清理](发布与清理.md)验收和提交。
