# 仓库定位与结构

仓库保存可交给不同 AI 的复刻任务，以及可体验、可重建的实现。共同任务描述同一个问题，执行者各自解决。成果供用户使用、研究与重建。

| 路径 | 用途 |
|---|---|
| [README.md](../README.md) | 看全部案例、缩略图与演示 |
| [tasks/](../tasks/README.md) | 按案例保存任务书、原始参考和允许资源；输入锁记录版本与摘要 |
| [catalog.json](../catalog.json) | 查已交付版本、文件和命令，通过 `task_manifest` 关联任务 |
| [series/](../series/) | 保存已完成的实现、正式页面、精选素材和系列研究资料 |
| [docs/](README.md) 与 [templates/](../templates/) | 人读的指南与可复制的空白模板 |
| [scripts/](../scripts/) 与 [tests/](../tests/) | 查任务、导出校验、仓库门禁和回归测试 |
| `local/`、`private/`、`artifacts/` | 取材、非公开资料与可生成输出。均由 Git 忽略 |

## 任务与版本

案例 ID 对应明确的目标对象和参考范围。一个案例可以有多个实现，也可以先发布任务、暂时没有成果。同一模型再次执行时可用有区分度的版本 ID。模型名、执行工具、视觉目标与实现来源分别记录。

```text
tasks/<case-id>/
  brief.md                 需求、目标和验收
  input.json               版本、资源约定、原始参考清单
  references/             允许分发的共同参考；local/ 仅本地
series/<系列>/models/<model-slug>/<case-id>/
  README.md                使用、重建、执行来源与限制
  index.html / film.html   已交付的网页（适用时）
  src/、tools/             实现与必要工具
  stills/ 或 assets/       精选预览与运行所需素材
  records/                可选的验收证据或机器契约
  artifacts/              日常 QA、帧、视频、音轨和中间导出
```

旧成果保留原路径与在线链接。内容按任务和成果区分，目录可沿用适合版本的技术布局。系列的角色研究档案与上游快照供浏览和重建，统一任务通过自己的白名单决定哪些内容可用。

## 入口

| 想做什么 | 从哪里开始 |
|---|---|
| 看作品 | [首页](../README.md#案例展示) |
| 交给 AI 独立复刻 | [任务目录](../tasks/README.md)，或 `python3 scripts/catalog.py list --tasks` |
| 重建已有版本 | `python3 scripts/catalog.py show <case> --variant <variant>`，按版本 README 执行 |
| 新增、整理或发布 | [贡献指南](../CONTRIBUTING.md)与[发布与清理](发布与清理.md) |
