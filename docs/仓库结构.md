## 系列目录

```text
series/
  机械复刻系列/
    models/<model-slug>/        模型工程，旧多案例项目共用构建链
    comparisons/<comparison>/  对比作品的说明、工具和预览
    docs/                       系列资料与历史记录入口
    <历史发布目录>/              原址交付的 HTML、静帧、封面与导航
  变形金刚系列/
    models/<model-slug>/<case>/ 模型工程与交付
    research/                  角色档案、来源、研究候选与索引
    docs/                      系列制作和发布说明
    references/boards/         保持原址的研究板
    01-擎天柱-电影版/            原址的首个擎天柱工程及发布资源
```

机械系列源码集中在 `models/`，旧发布目录沿用原 URL。首个擎天柱的导出、QA 和渲染契约共享同一工程根，通过模型索引访问。新成果使用 `models/<model-slug>/<case-id>/`，根 README 先链接正式交付，再给重建与验收。

## 日常入口

- 体验作品用[首页](../README.md#案例展示)或系列首页。
- 独立复刻从[共同任务](../tasks/README.md)导出并校验输入包。
- 重建已有版本用 `python3 scripts/catalog.py show <case> --variant <variant>`。
- 查本机产物用 `python3 scripts/workspace.py <case> --variant <variant>`。
- 新任务与成果登记见[贡献指南](../CONTRIBUTING.md)，公开范围见[发布与清理](发布与清理.md)。
