# 通用基础与约定

这是维护者和成果开发者的工程建议。冻结输入以各任务包为准，参数与实现由执行者独立建立。精细视觉校准见[精细复刻流程](精细复刻流程.md)。

## 参数与来源

- `frame`：可从参考图读出的相对关系；`ref`：有链接的资料值；`guess`：估算/设计值；`calc`：给公式和输入的推导值。
- 无标尺的图片不能证明绝对尺寸，设计遥测不等于物理测量。动态面板由同一状态计算；固定型号、单位与文案可以是静态文本。
- 模型 ID、工具版本、成本和耗时以证据为准，未记录就写未记录。新写提示词不伪称历史原文。
- 时间记录带时区，默认 Asia/Shanghai。状态用已完成、部分完成、只记录未做，并写清范围。
- 视觉目标（还原/改编）与实现来源（独立/衍生）分别声明。仅任务明确允许的代码资源可复用，保留许可与署名，不将衍生冒充独立。

## 确定性动画与导出

代码动画提供时间驱动的渲染接口，画面由 `t` 或帧号决定。交互播放可用时钟驱动，但逐帧导出要冻结播放器、CSS 动画、随机与累积状态。有状态系统要重置或预滚；检查 `t1 → t2 → t1` 的状态和画面。

浏览器逐帧截图，经管道送 FFmpeg 编码。例如 60 fps PNG 管道：

```text
ffmpeg -y -f image2pipe -framerate 60 -c:v png -i - -c:v libx264 -preset slow -crf 16 -pix_fmt yuv420p -movflags +faststart out.mp4
```

音轨来自同一时间线，素材许可另行说明。用 ffprobe 核对实际分辨率、帧率、时长与音轨；逐拍静帧和转场检查不能被 blackdetect 等自动指标取代。没有音轨就如实写明。

## 交付与可复现

1. 成品可打开；源码、锁文件、首次安装与产物位置明确。
2. 自动断言验证有意义的约束；人工检查轮廓、比例、机位、材质、动作和遮挡。
3. 测试日志区分当前实测、历史记录和未验证。相似度和零网络不能当作视觉评分。
4. 代码依赖按操作系统适配，路径相对于脚本位置解析；不写本机路径、密钥或个人会话。
5. 精简公开证据；完整渲染中间文件留 `artifacts/`，参考原视频留 `local/`。

现有机械页面采用单文件离线策略；新媒介自行定义合适交付方式。不要把“中文界面”“指定蓝色”“全程运镜”“唯一物理自由度”设为所有未来案例的硬规则。
