# 真人电影角色参考库

67个角色/版本的研究入口，覆盖2007–2023真人电影主角群、常用反派、恐龙/巨无霸、合体与伴随角色。**参考档案不自动计作成品；已完成实现另外登记。** 大黄蜂已有[Codex 独立研究模型](../models/codex/bumblebee-2007/README.md)。不声称穷尽动画、漫画、游戏或电影背景群众角色。

[返回系列](../README.md) · [结构化索引](../character-library.json) · [制作协议](../工作流协议.md)

62个档案含144张实际核验的官方产品样例；其余5个提供角色对应的原片片段或图证入口，尚未抽帧。产品图只作授权衍生外观补充，原片镜头尚未逐角色测量。公共仓库提供精选缩略研究板、URL/尺寸/摘要与结构候选，原始大图保存在各角色 `local/`。

## 使用

```bash
python3 "series/变形金刚系列/tools/characters.py" list
python3 "series/变形金刚系列/tools/characters.py" show 大黄蜂
python3 "series/变形金刚系列/tools/characters.py" fetch bumblebee-2007
python3 "series/变形金刚系列/tools/characters.py" start bumblebee-2007
python3 "series/变形金刚系列/tools/characters.py" check
```

`show` 浏览来源与研究候选；研究候选不自动属于独立复刻输入。`fetch` 只获取有冻结摘要的直链图片到local；片段/论文图证按清单人工抽帧登记。来源内容变化时拒绝保存，不冒充历史同一份素材。`start` 在experiments下创建不覆盖的草稿，默认只复制来源元数据，不复制计划拆分，装配与几何由执行者自行建立；不会复制擎天柱，也不登记为成品。

结构覆盖头/脸/颈、胸脊腹骨盆、肩肘腕掌、髋膝踝足、内撑/转轴/滑轨/活塞/线束/紧固件，并按车型、飞行器、兽形、三变、合体和行星形态增加专有模块。去向与轨迹初始为空；指节和轮胎数量不默认套用擎天柱。

## 证据界线

“官方产品图”不等于“电影原始机构”。伴随角色可能与主角色共用套装图集，开工前须确认独立视图；2017恐龙产品线不证明电影内出场镜头；三变和合体的商品结构不直接作为原片唯一物理拓扑。每个档案均列出这些未知项。

片段/图证来源包括Paramount官方宣传、Movieclips发布的原片片段、UEA公开学术图证；仅链接，不随代码再授权。没有从粉丝搬运、同人模型或其他年份的同名角色偷偷补造型。电影出场、版本身份、具体车体和转轴仍需逐案例复查。

只有任务明确把结构研究候选列为共同输入时，才使用 `start <角色> --with-structure`；所有对照版本应采用相同选择。既有实现的源码、参数和过程始终不在默认输入中。
