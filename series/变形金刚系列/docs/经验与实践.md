# 可复用经验

## 先保证形体，再增加密度

轮廓、比例、相机和姿态决定角色辨识度。先用原片地标对齐车辆与人形，再做曲面、外甲/骨架层次、指节和活塞。装配节点、视觉小件、合批 Mesh 与真实自由度分开计数；零件数量不能证明还原质量。

电影画面、制作幕后和授权产品图分别登记。玩具可以补充外观观察，不能替代电影机构证据；未知尺寸、藏件和连接继续标为推断。局部展开、能量工具和分层拆解属于展示设计时应明确说明。

## 同一模型贯穿网页与影片

每个实体只有一个稳定 ID 和归属，在车辆、人形及中段保持身份与尺度。动作使用可重入的纯时间函数，保存姿态与相机；装配追踪按需生成到 artifacts，不把全部矩阵塞进展示文档。

通用接口使用头、躯干、手足、翼、尾尖或行星环等语义端口。镜头先按端口与包围盒取景，再目视调整；不能把擎天柱坐标或轮数变成其他角色的默认值。第二角色验证之前，复用协议与工具方法即可。

## 正式渲染前关闭构图问题

先检查车辆、人形、中段和每个特写。特写要看得清机构，远景要保留剪影和足部；投影包围盒只辅助检查取景，不是美学评分。研究侧视相机也要检查场景遮挡：距离主体合适不代表在墙内，收回侧向机位后需调整视角保持取景。镜头变化围绕解锁、分离、展开、锁止和重组的动作事件，切点保持运动方向与速度。

导出与渲染共享排他锁，冻结网页、GLB、相机、场景、HDRI、字幕和剪辑指纹。重导出按摘要另存，不覆盖唯一资产；输入变化时重新渲染相应帧，不能直接沿用旧缓存。

GLB 的异步图片封装可能使原始字节摘要变化，而解析数据相同。解析摘要用于诊断，正式缓存仍校验原始文件；不能把所有摘要差异都解释为封装顺序。

## 成片兼顾视觉与能力展示

电影镜头负责氛围、材料与体量；真实网页录制负责证明操作能力。保留可读的滑杆、节点选择、组合展开和拆解重组，用短章节和温和转场衔接。录制源保持完整操作时间表，剪辑记录源区间；不伪造不存在的功能。

配乐记录作者、曲名、许可、来源、截取位置和修改，必要署名同时进入片尾和随附文案。检查实际输出文件的解码、帧数、声道、响度、峰值、黑帧、字幕遮挡与完整播放；自动数值通过仍需人工试听和艺术评审。
