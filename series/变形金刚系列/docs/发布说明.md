## 复用与发布检查

既有离线网页可直接打开。新独立复刻先取齐并核验任务包；研究板留作来源浏览。冻结参考的字节发生变化时，按[输入版本规则](../../../CONTRIBUTING.md#新增或修订任务)重新登记。

```bash
python3 scripts/check_repo.py
python3 -m unittest discover -s tests -v
python3 "series/变形金刚系列/tools/characters.py" check
python3 scripts/check_transformer_contract.py "cases/optimus-prime-2007/models/gpt-6-1-sol/production.json" --require-ready --require-local-media
# 暂存后检查实际发布候选，而不是带缓存的工作目录：
python3 scripts/check_clean_checkout.py
```

`catalog.json` 只登记已有实现；资料库另列。GitHub Pages 沿用仓库 main 根目录部署。发布检查不替代造型评审、完整碰撞检测和人工听审。
