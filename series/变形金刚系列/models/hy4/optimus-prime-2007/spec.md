# 规格 · HY4 擎天柱（2007 真人电影版）

数值来自本轮程序化建模与官方素材观察。来源类型：`frame`（读图）、`ref`（外部资料）、`guess`（估算）、`calc`（推导）、`designed`（展示设计）。**没有标尺的世界尺寸只能是 `guess`，写成单位也不等于真实尺寸；PBR 参数是实现推断，不是原作扫描数据。**

## 状态机与时间线

| 参数 | 值 | 说明 |
|---|---:|---|
| 源时间线 | 50 s | `production.json` / `rig.mjs` |
| 完整变形区间 | 8–19 s | 37 个装配按各自 `delay` 窗口错峰重组 |
| 帧率 | 24 fps | 与仓库既有成片一致 |
| 端点静止 | t ≤ 8 全车 / t ≥ 19 全人形 | 支持 `t1 → t2 → t1` 回放校验 |
| 中段避让 | 每个装配 `arc × sin(πu)` 确定性弧线 | `inferred`，不是实测轨迹 |
| 展甲 `deploy` | 0–0.85，REVEAL → HEAD_CHEST 渐增，REASSEMBLY 收回 | `designed`，本轮展示动作 |
| 分层拆解 `explode` | 0–1，黄金角方向 + 按装配错峰幅度 | `designed`，24.5–26.5s 展开、26.5–28s 收回 |
| 最大 0.2s 位移 | 0.445 世界单位 | `calc`，`tools/check.mjs` 实测 |

`stateAt(t, opts)` 为纯函数；默认 `deploy=explode=0` 时端点严格静止。展示动作只叠加在成片取帧，不改变契约端点，也不隐藏实体或换模型。

## 镜头与成片

| 镜头 | 成片区间 | 源时间 | 目的 |
|---|---|---|---|
| IGNITION | 0–4 s | 0–8 s | 低机位¾车辆建立，缓慢推进 |
| TRANSFORMATION | 4–15 s | 8–19 s | **1:1 连续镜头，不切镜，完整覆盖变形** |
| REVEAL | 15–19 s | 19–23 s | 人形亮相，短暂停顿读剪影 |
| HEAD_CHEST | 19–22 s | 23–26 s | 头胸揭示，展甲带出内构 |
| LOWER_BODY | 22–24.5 s | 26–28.5 s | 髋膝踝与足部承重 |
| EXPLODED | 24.5–26.5 s | 28.5–30.5 s | 分层拆解（明确标为本轮设计动作） |
| REASSEMBLY | 26.5–28 s | 30.5–32 s | 同方向收束、缓收落幅 |

| 成片参数 | 值 |
|---|---|
| 画幅 / 帧率 / 帧数 / 时长 | 1920×804 / 24 fps / 672 帧 / 28.000 s |
| 视频 / 音频 | H.264 (CRF 18, yuv420p) / AAC 192k 48kHz 双声道 |
| 渲染方式 | 同源模型逐帧 WebGL PBR 确定性重绘 → PNG 序列 → FFmpeg 编码 |
| 音轨 | 原创程序化合成，9 个事件；电平 mean −14.5 dB / peak −1.4 dB |
| 验收 | 672 帧齐全、完整解码无错、黑帧 0、逐帧镜头指纹归档 |

镜头边界全部落在整帧；`TRANSFORMATION` 段是唯一连续覆盖完整变形的镜头，符合生产契约。4 s 切点从车辆近景切到变形远景，主体屏幕尺寸有明显变化，属于设计切点，记录在[差异合同](records/参考测量与差异合同.md)。

## 不能由本规格推出的量

真实内部铰接、全部隐藏面、精确世界尺寸、所有零件连续去向、碰撞与承重、原始速度/加速度、材料真实 BRDF、原片同机位像素误差。这些继续列在 `production.json` 的 `unknown`，不因分件数、路径追踪名词或自动测试通过而消失。
