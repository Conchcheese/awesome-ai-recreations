- **并行会话说明**：初版收口时工作树中另有 `experiments/optimus-prime-2007/` 草稿（自署 GLM-5.3-Flash，注明 `models/hy4/` 已由另一会话占用）。本版几何、渲染、契约与页面在此之前已独立完成；排查工作树时仅读取该草稿的 README 与 `production.json` 以确认来源，**未使用其任何几何、参数、源码或截图，也未修改该目录**。两个版本互不合并、互不冒充。

## 实际工具与命令

- Node.js v22.22.2；Three.js 0.186.1；esbuild 0.28.1；Playwright 1.58.2 + Chromium（Metal / SwiftShader）；FFmpeg / ffprobe；Python 3 + Pillow。
- Blender 4.5.4 LTS 便携版在本机可执行（已用 `-b --python-expr` 验证），但**本轮成片未使用 Blender**，不冒充 Cycles 路径追踪。
- 从本案例目录执行（`NODE_PATH` 指向同系列已锁定依赖）：

```bash
export NODE_PATH="../../../01-擎天柱-电影版/node_modules"

node tools/build.mjs      # esbuild 打包 src/ → 内联 index.html / film.html（各 1.30 MB）
node tools/audio.mjs      # 原创 WAV：48kHz 双声道 28.00s，峰值 0.880，9 个事件
node tools/render.mjs     # 672 帧逐帧离线渲染 → artifacts/frames/*.png
node tools/video.mjs      # FFmpeg 封装 + ffprobe / 完整解码 / blackdetect / volumedetect
python3 tools/contact.py  # 从编码后 MP4 解码抽帧 → 接触表 / 分镜 / 原作并排 / 50% 叠图

node tools/check.mjs      # 36 项数据契约、状态机、几何、镜头、页面、影片门禁
node tools/qa.mjs         # 15 项 DOM 契约 + 真实 Chromium 实跑
python3 ../../../../scripts/check_transformer_contract.py production.json --require-ready --require-local-media
python3 ../../../../scripts/check_repo.py
python3 -m unittest discover -s ../../../../tests
```

## 人工视觉审看记录

- **R1 → R2**：车辆端零件散架、人形比例失调、头部裁切；重算 37 个装配的双端位姿与自适应相机后，两端轮廓可读。
- **R2 → R3**：胸窗被胸甲遮挡、肩甲呈圆球、车尾缺平板；调整胸窗/胸甲层级、压扁肩甲球壳、扩车尾平板后修复。
- **成片解码接触表审看**：0.5–2.5 s 车辆建立、4.5–8.5 s 零件分离、10.5–18.5 s 人形、20.5 s 头胸、22.5 s 下肢、24.5–26.5 s 拆解均可读；**发现后半段人形几乎静止、拆解位移过小**，因此加入 `deploy` 展甲与黄金角 `explode` 拆解曲线并**全量重渲**，复审见 `artifacts/qa/v3-动作接触表.jpg`。
- **切点**：4 s 从车辆近景切到变形远景，主体屏幕尺寸骤变，已登记为设计切点，未做速度连续性优化。
- 听感与艺术质量只做技术检查（响度、峰值、黑帧、完整解码），**未替代人工试听与艺术评审**。

## 未验证项

- 原片同机位量化轮廓误差、注册叠图像素差、还原度百分比——**未做，不给**。
- 完整碰撞检测、实体可制造性、真实内部拓扑与铰链——**未知，不写「无穿模」**。
- 世界尺度、隐藏面、背面藏件、真实材料 BRDF、原始速度/加速度——`guess` / `inferred`。
- Blender Cycles 路径追踪、GLB / Blend 导出、逐帧运动模糊、跨 GPU 像素一致性、手机窄屏、伪竖版——**本轮未做**。
- 展甲、分层拆解、重组、机库环境与原创配乐为 `designed`，不是原片已证实的能力或场景。
- 精确模型 ID、完整提示词、迭代轮次与人工介入次数未归档；不用于模型对比或能力排名。
