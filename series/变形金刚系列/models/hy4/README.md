# HY4 · 变形金刚复刻

模型署名 `HY4 / Tencent Hunyuan Hy` 由用户指定标注，沿用仓库机械系列的历史署名口径。本目录收录该模型在变形金刚系列下的独立实现，**与 GPT-6.1 Sol 的既有作品分开保存**。

## 当前成果（2026-11-06 重做）

- **三维**：37 个可动装配 / 490 个命名视觉分件 / 974 个 Mesh；Three.js `MeshPhysicalMaterial` 九类材质分区，程序化环境反射、火焰纹与磨损贴图，ACES 调色与机库尺度。
- **动作**：50 秒源时间线，8–19 秒同一批实体错峰连续变形；展甲、分层拆解与重组明确标为 `designed` 展示动作。
- **成片**：`optimus-prime-2007/artifacts/HY4-擎天柱-2007-电影版.mp4` —— 28 秒 / 24fps / 1920×804 / 672 帧 / H.264 + AAC；同源模型逐帧离线渲染 + 原创程序化音轨，已做解码、黑帧与电平验收。**不是网页录屏，也不是 Cycles 路径追踪。**
- **证据**：解码接触表、分镜、原作并排与 50% 叠图、逐帧指纹、36 项数据门禁与 15 项浏览器 QA。

初版为 57 个色块的 Canvas 2D 投影且无影片；用户指出粗糙后按[精细复刻流程](../../../../docs/精细复刻流程.md)整体重做，逐轮差异见[参考测量与差异合同](optimus-prime-2007/records/参考测量与差异合同.md)。

## 署名与执行边界

- 本次会话在 WorkBuddy 环境内独立编写几何、状态机、渲染、镜头、音轨与验证脚本，**未另行调用带版本号的 HY4 模型 API**；精确模型 ID、完整提示词与迭代轮次未归档。
- 模型名称、视觉目标、实现来源、工具链与未验证项分别登记在案例的 [production.json](optimus-prime-2007/production.json) 与[实现与验证](optimus-prime-2007/records/实现与验证.md)。
- 署名不证明独立创作已被第三方审计、不证明模型身份已核验、不用于模型能力排名。
- 该实现只读取登记的 15 份官方素材与仓库方法文档；既有电影版与已归档原型的几何源码和规格不作为输入。既有案例 `node_modules` 中的 Three.js / esbuild / Playwright 仅作已锁定的构建依赖复用。
- 原始影片、逐帧缓存、成片与便携工具留在被忽略的 `local/` / `artifacts/`，按系列发布说明处理。

历史署名口径见[机械系列 HY4 独立直出版](../../../机械复刻系列/hunyuan直出版/README.md)与[NOTICE](../../../../NOTICE.md)。新增模型请按[版本与目录约定](../README.md)建立独立实现；[系列作品](../../README.md)为案例导航。
