# 大黄蜂 · 当前实现规格

目标为 2007 真人电影版外观；实现来源 independent。两张 MPM-3 官方产品原图是外观补充，未取得电影原帧测量，不把本版称为电影等同资产。

| 项目 | 当前实现与依据 |
|---|---|
| 单位与坐标 | Blender 单位；X 左右、−Y 朝前、Z 向上。全部世界尺寸 guess |
| 人形 | 约 5.9 单位高，黄色黑纹车甲、分裂车头胸甲、门翼、四轮、蓝眼、分段指节与滑动面罩 |
| 装配 | 43 个固定身份装配，612 个命名视觉分件；不是实际自由度计数 |
| 变形 | 源时间 3.1–9.5 秒，错峰平移/转动；一段连续镜头覆盖，固定尺度、可见实体数量保持不变 |
| 局部动作 | 11.2–12.5 秒面罩闭合，轻微头转与躯干起伏；展示设计 |
| 材质 | 黄漆与黑纹涂层、钛金属、深色骨架、铝、橡胶、烟色玻璃、蓝色光学与车灯 |
| 影片 | 22 秒、24fps、528 帧，原生 1920×804，Cycles 12 samples 上限、adaptive minimum 4、降噪；无后期升频 |
| 镜头 | 车辆低机位 → 连续变形 → 头胸与面罩 → 手臂 → 全身英雄镜头 |
| 声音 | NumPy 原创合成配乐与事件音效，48kHz 双声道；未采样影片配乐/对白 |
| 网页 | 同源 GLB 内联至两份离线 HTML，Three.js PBR；与 Cycles 的光照及后处理不同 |

## 原图观察与偏差

原图可见车头形成胸部、肩部轮组、黄色黑纹、蓝色双眼、门翼和较厚的下肢外甲。原图不是电影资产，也没有提供可校准的世界尺度。

当前车壳与头雕偏方，车型轮廓不够接近 Camaro；车体闭合、甲片叠层和背部收纳明显简化。变形是具有固定零件身份的空间展示推演，中段存在交叠，未实现经过碰撞求解的机械拓扑。没有声称物理可制造、无穿模、电影还原度或与 ILM 网格相同。

网页的分层展开是研究设计；不存在电影原帧证实这些展开幅度的结论。没有逐帧运动模糊或原片同机位差异评分。
