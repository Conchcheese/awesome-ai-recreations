# 实现与验证

## 已执行

- 以两张已登记的 MPM-3 官方产品图为外观补充，冻结独立输入包并记录摘要；未读取其他角色的几何实现源码。
- 建立 43 装配、612 视觉分件的独立模型，经历三轮实际 Cycles 样张复查。修正裁切、过曝、轮毂单面、车顶颈部穿出和默认网页机位问题。
- Blender 检查：零件 ID 唯一；装配状态可重入；多个车形／人形／中段时间点的实体数量和尺度不变。
- 浏览器检查：离线 file URL 加载、612 Mesh、车辆／人形按钮、灰模、键盘操作分层滑杆和时间跳转回放；无页面脚本错误。
- 渲染缓存防护：六个测试覆盖完整缓存、场景变更、后段缺帧、PNG 损坏、错误尺寸和目录越界。
- 系列生产契约通过，包括原始媒体摘要、零件唯一归属、语义端口及完整变形连续镜头覆盖；此检查不验证物理或造型。
- 取景检查：10 个车辆／变形／英雄时刻全部通过；对车轮包围框空角用真实评估网格细化。修正变形初段约 4 像素的轮胎边缘裁切后，用新指纹重渲染，旧批次未混用。
- 新增案例后的 39 项仓库测试通过。原有“参考库角色不能有成品”的断言改为“成品必须有独立源码、HTML 与有效 study 契约”，参考档案仍不自动计作成品。

## 成片验收

- 实际 MP4：22.000 秒、1920×804、24fps、528 帧、H.264/AAC；全片完整解码通过，未检测到异常黑帧或超过 1 秒的冻结。
- 实际音轨：48kHz 双声道；−18.2 LUFS，真峰值 −1.3 dBFS。声音为原创合成；数值验收不等于人工听审。
- Chromium 初验和提交前复验均播放到 22 秒片尾，解码 528 帧。两次分别报告丢 2 帧和 0 帧，机器可读摘要记录复验结果。
- 实际 MP4 的 9 张解码联系表已审看；片名未遮挡主体。精选静帧均来自成片，清除 EXIF 并登记摘要。
- [完整机器可读摘要](验证摘要.json)记录渲染指纹、影片摘要、媒体参数、自动播放与取景检查。


## 仍有差距

| 差异 | 本轮处理 | 限制 |
|---|---|---|
| 轮廓和头雕简化 | 补轮拱、门翼、颈部、蓝眼、面罩与分段手指 | 与电影 Camaro 及头雕明显有差距，无原片同机位测量 |
| 车体闭合与藏件 | 同身份装配、错峰平移和转动 | 中段交叠和收纳不物理；未做完整碰撞 |
| 镜头裁切与过亮 | 三轮样张后调整相机与漆面 | 不能以构图检查替代艺术评价 |
| 网页与离线渲染差异 | 同源 GLB 与同一动作函数 | 光照、环境反射、降噪、景深不同；不声明逐像素一致 |

精确模型 ID、电影内部尺寸与隐藏拓扑未知。未做人工听审、原片逐帧造型测量、实体动力学验证或跨 GPU 像素一致性验证。Blender 4.5.4 复查时输出一条 `NodeSocket.default_value` 警告，模型检查正常完成。
