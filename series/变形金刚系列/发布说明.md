## 复用与发布检查

既有离线网页不依赖原始参考下载。新复刻必须先依据来源清单取材，研究板不替代电影逐帧测量；冻结摘要不一致时建立新的取材记录。

```bash
python3 scripts/check_repo.py
python3 -m unittest discover -s tests -v
python3 "series/变形金刚系列/tools/characters.py" check
python3 scripts/check_transformer_contract.py "series/变形金刚系列/01-擎天柱-电影版/production.json" --require-ready --require-local-media
# 暂存后检查实际发布候选，而不是带缓存的工作目录：
python3 scripts/check_clean_checkout.py
```

`catalog.json` 只登记已有实现；资料库另列。GitHub Pages 沿用仓库 main 根目录部署。发布检查不替代造型评审、完整碰撞检测和人工听审。
