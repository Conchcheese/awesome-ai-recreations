# 2007 真人电影擎天柱 · 规格与还原合同

## 属性与边界

目标 fidelity；来源 derived。沿用前一版构建/导出方法，模型、机构、材质、摄影和声音重写。原始电影与ILM幕后是主要造型依据；MPM-4只补充表面观察，不能当电影物理机构。详见[任务书](../prompts/optimus-prime-2007.md)。

坐标：Y向上、Z朝前；模型单位u没有实物标尺，不能自动当作米。主比例、隐藏结构、铰接路径均为guess。实际输入边界与15个可见地标见[原帧合同](records/参考测量与差异合同.md)。动态仰拍不能伪装正交三视图。

## 系统层级与细分

| 系统 | 可操作装配 | 车辆到人形/展示的去向 |
|---|---|---|
| 胸部 | 分体胸窗、窗框、车顶瓣、上下门甲分片、下胸翼 | 驾驶室各面板倾转为胸甲，局部可分层打开 |
| 核心/脊柱 | 承力轨、交叉架、分节脊柱、机械转子、腹部多层甲片 | 保持内部骨架，核心检查含设计动作 |
| 肩部 | 肩轴、曲面火焰轮拱、下甲瓣、齿轮/滚道、轮组 | 车头/轮组迁移，甲片独立开合 |
| 手臂 | 肱骨、肘轴、液压/线束、前臂框、三瓣护甲、侧甲 | 车头覆盖件与前臂重构，工具可部署 |
| 手部 | 腕节、掌骨、拇指两节、其余四指三节 | 指节可分别受驱动，不是一整块拳头 |
| 髋腿 | 髋横架/滑移、股骨活塞与护甲、膝轴、胫骨骨架、分体腿甲、踝轴、三足尖 | 后底盘折叠/转向成腿，护甲分瓣展开 |
| 背部 | 车体后板、通风片、排气主/支管、热护罩 | 背甲开合，烟囱保持独立组件 |
| 轮组 | 六个轮位、十条实体轮胎、轮毂/孔/螺栓/胎块 | 前轮迁移至肩背、后轮到髋腿侧，非G1简单腿尾轮列 |

静态小件合批只降低draw call，全部视觉分件仍在 `records/assembly-catalog.json` 有归属。独立装配数不是严格物理自由度数；共享驱动会联动多个节点。

## 时间线与运动

`rigAt(p,extra)` 纯函数输出变形量、各系统展开、拆解、握指、工具、落地缓冲和视线/躯干转向。`apply` 每次覆盖所有节点位置/旋转；无累积姿态。头部可有固定比例缩放，所有动画状态保持各装配体积不变。

变形次序：外甲解锁 → 驾驶室分瓣 → 手臂延展 → 车头/发动机迁移 → 后架翻转/腿部转向 → 头颈展开 → 落位与支撑。前后原片有剪辑，当前路径是可观察特征约束下的三维推演，不冒称每块原始零件已经追踪完成。

- 0–8秒：车辆/启动与抵达镜头。
- 8–19秒：连续完整中景变形。
- 19–24秒：低机位亮相，膝踝轻微落地缓冲。
- 24–29秒：胸甲分层与机械核心检查。
- 29–34秒：前臂三瓣与能量工具，指节握合。
- 34–38秒：腿甲/肩甲/背甲的分瓣联动。
- 38–43秒：多层装配拆解。
- 43–46秒：重组。
- 46–50秒：头部/躯干转向与最终机位。

电影短片按 `tools/edit.py` 将以上镜头选段重定时为28秒；24fps真实逐帧渲染，无插帧补帧。7秒连续变形段保留完整姿态路径。全片10个镜头，按镜头编号区分有意硬切与异常跳变。

## 几何、材质、渲染

曲面甲壳/闭合薄板有厚度，主要边缘有倒角；关节使用轴/滚道/液压筒/伸出杆等分层件。烟囱、轮胎、格栅、线束有单独材质。表面纹理为确定性生成的颜色、粗糙度、微法线、边缘缺漆与划伤；不是实物扫描，也未测得原始材料参数。

材料分为清漆红/钴蓝/火焰漆、机加工钢、拉丝合金、铬、热色钛、铜、含油暗金属、复合黑、橡胶、层压烟色玻璃、光学发光与能量投影。PBR参数、HDRI强度和光源均为展示估算。玻璃不是替换成发光平面；电影版没有大面积HUD遮挡主体。

网页：Three.js PBR、HDRI反射、面光/轮廓光、阴影、SSAO、景深、局部辉光、输出后的轻微颗粒。离线：同源GLB/每帧镜头 → Blender 4.5.4/Cycles/Metal，路径追踪、真实接触阴影/反射、景深与分镜剪辑。网页与Cycles色调映射不同，不声称像素一致。

## 必须验证的约束

1. 节点/视觉分件身份不变、矩阵有限、相对于静态比例的体积恒定；正反/重入没有累积状态。
2. 车辆六轮位共同接地，收纳件不低于轮胎；两端和中段地面最低点约束。此约束不等于真实接触/重心/全程零件碰撞。
3. 每个系统至少有多个独立节点真实移动，不能只整体平移假装精细展开。
4. 原始帧/灰模/同状态对照；未匹配机位时不计算还原度百分比。
5. 浏览器按钮、分层滑杆、选择、高亮/灰模、移动端与控制台；姿态/相机严格重入，后处理像素差异另记。
6. 视频实际分辨率、帧率、帧数、音轨、黑帧/冻结、镜头切点、字幕遮挡和声音峰值。人工听审未完成时明确标出。

## 已知不足

仍无ILM原始拓扑/CAD/完整三视图；部分造型简化和设计化仍在。隐藏面、全程零件间碰撞、承重与原作每帧速度尚未验证。当前严格最低点支撑是几何约束，不能当真实动力学。具体差异和修订见[验证记录](records/实现与验证.md)。
