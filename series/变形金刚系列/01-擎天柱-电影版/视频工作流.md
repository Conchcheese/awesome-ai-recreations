# 电影与网页功能演示视频

成片结合同源 Cycles 镜头、真实网页操作和带许可的电影配乐。电影片段采用已冻结的 v0.1 Cycles 成片，展示材料、细节与体量，网页实录来自当前页面，展示可操作的功能；新视频保留本地，不自动上传 Release。

## 编排

车辆建立 → 连续变形 → 网页双形态与独立展开 → 电影头胸/前臂特写 → 网页组合开合、节点选择与灰模分色 → 分层拆解电影镜头 → 网页分层滑杆与重组 → 英雄亮相 → 署名片尾。段落之间使用 0.36 秒叠化，章节短标题避开网页按钮。

`tools/capture-showcase.mjs` 在真实 Chromium 中点击按钮、拖动滑杆和相机，记录完整操作时间表、页面错误和 HTML 摘要；没有调用姿态 API 代替操作。`tools/showcase.py` 按该时间表剪辑，分别保存电影渲染与当前网页的 HTML 摘要、源区间、音乐修改及文件摘要到 artifacts。替换角色时先调整其实际控件与镜头，再复用录制和剪辑方法。

## 复现

先按[案例 README](README.md)安装依赖，从[Release](https://github.com/topmindspace/awesome-ai-recreations/releases/tag/transformers-study-v0.1.0)下载 v0.1 影片，并保存为 `artifacts/擎天柱-2007-电影版-Cycles.mp4`；脚本依据公开验证摘要校验影片，不依赖作者本地渲染日志。从[作曲家官方页面](https://www.scottbuckley.com.au/library/titan/)下载 Titan 到本地目录，然后从仓库根执行：

```bash
node "series/变形金刚系列/01-擎天柱-电影版/tools/capture-showcase.mjs"
python3 "series/变形金刚系列/01-擎天柱-电影版/tools/showcase.py" --font "/实际安装的中文字体文件" --music "/本地/sb_titan.mp3"
```

需要 FFmpeg/ffprobe、Pillow、Playwright Chromium 和系统已有中文字体。编码后执行 `python3 "series/变形金刚系列/01-擎天柱-电影版/tools/check-showcase.py"` 和 `node "series/变形金刚系列/01-擎天柱-电影版/tools/playback-check.mjs" --showcase`，分别检查实际媒体和完整播放。

输出为本案例 `artifacts/擎天柱-电影与网页功能演示-BGM.mp4`，1080p/25fps/H.264/AAC；字幕、片尾、实录、操作表和剪辑记录在 `artifacts/showcase/`。网页实录保留真实渲染性能，不能靠编码帧率宣称每帧都是新画面。

## 配乐署名与检查

> 'Titan' by Scott Buckley - released under CC-BY 4.0. www.scottbuckley.com.au

[曲目与许可](https://www.scottbuckley.com.au/library/titan/) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [作者使用说明](https://www.scottbuckley.com.au/library/using-this-music/)。本视频使用截取、淡入淡出和响度调整；没有采样电影配乐。署名进入片尾、MP4 元数据及同名 TXT。如上传 YouTube，按作者要求将署名放入视频说明。

检查实际 MP4 的完整解码、时长/帧数、48kHz 双声道、响度与峰值、黑帧、转场和文本遮挡，再完整播放。听感和艺术质量需要人工评审，不能只以自动通过结论替代。

## 机械音效

完成剪辑后运行 `python3 "series/变形金刚系列/01-擎天柱-电影版/tools/showcase-sound.py"`，叠加原创程序化引擎、伺服、滑轨与锁止声，并对配乐轻度避让。输出保留原视频流，声音单独重编码。音效是机构展示设计，不是原电影采样或真实设备录音。

电影段按源剪辑时间定位，网页段按 capture.json 操作标记及 1.4 秒展示动画估算落位；未宣称采样级同步。`mechanical-cues.json` 保存事件、时刻和时长；纯视觉开关不添加重型撞击。重复运行从保留的 visual-master-bgm.mp4 混音，不累计叠加；重做画面后须先归档并移除旧母版，重新生成。混音后重新运行媒体检查与完整播放，人工试听确认切点、空间感和重量感。

## 动作音效加强版

混音以音乐母版为输入，分别保存机械声和配乐。齿轮运动使用多谐波电机、棘轮与摩擦噪声；锁止使用短金属瞬态及共振，避免所有动作都变成低频敲击。运动窗口压低配乐，40ms 平滑音量变化；声音仍是展示设计，非原片采样。

运行 sound 工具后输出 `artifacts/擎天柱-动作机械音效加强版.mp4`；纯机械音轨为 `artifacts/showcase/mechanical-effects.wav`，`sound-balance.json` 记录有声窗口的音效/配乐相对电平。该指标用于发现掩蔽，不替代试听；网页锁止点仍按操作标记与动画时长估计。换剪辑需重新建立音乐母版，摘要不匹配时工具拒绝混音。保留独立音轨供后续角色调音，不将整条擎天柱音轨套用其他角色。
