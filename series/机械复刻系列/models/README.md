这里是源码、依赖、规格和重建命令的入口。互动页、巡览页和精选图沿用发布地址。

| 项目 | 案例 | 使用与重建 |

| GPT-6.1 Sol | 机械章鱼 OC-8 | [项目说明](gpt-6.1-sol/README.md) |

| GLM 5.3-Flash | 九个机械案例、共用构建工具 | [项目说明](glm-5.3-flash/README.md) |
