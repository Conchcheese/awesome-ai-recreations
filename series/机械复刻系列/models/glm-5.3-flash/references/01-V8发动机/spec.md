# V8 发动机（四冲程 · 90° 十字曲轴）— 造型规格

来源：teardown 示例 `v8-shared`（复刻基底，结构不改），参考图 `v8-参考-雪佛兰小缸体V8-实车.jpg`
（Chevrolet 小缸体 V8，Automobile Driving Museum，Wikimedia Commons 4060×3595）。
每个数字标注来源：`code`（kin.js/engine.js 代码实值）| `ref`（参考图/真实发动机公开数据）| `guess`（估算）。

## 1. 部件清单（与参考图对应）

| 部件 | 数量 | 形状 | 来源 |
|---|---|---|---|
| 气缸体 + V 型两列气缸 | 2 列 × 4 缸 | 90° 夹角，玻璃缸套可见活塞 | code + ref |
| 十字曲轴 | 4 曲柄销，互成 90° | 前端曲轴方向箭头（本版为钴蓝） | code |
| 连杆 + 活塞 | 8 组 | 精确滑块曲柄解算 | code |
| 顶置凸轮/摇臂 | 每缸 2 气门 | 进气/排气弹簧气门 | code + ref |
| 飞轮 | 1 | 大直径黑盘，后端 | code |
| 曲轴皮带轮 + 转向箭头 | 1 | 前端，双弧箭头标旋转方向 | code |

| 缸体主体 | 1 | 亮黑机身，白色活塞 | code |

## 2. 唯一输入

曲轴角 θ（度）。影片中转速 700 → 2400 rpm（12.1 s 起 1.4 s 缓动），回放 1/20 速度。
θ 随时间积分（film.js 预积分表 TH），一切姿态与读数都是 θ 的纯函数。

## 3. 尺寸与参数（毫米 / bar / rpm）

| 参数 | 值 | 来源 |
|---|---|---|
| 缸径 bore | 101.6 | code（≈4.00 in，典型小缸体） |
| 曲柄半径 r | 44.5 | code → 行程 2r = 89 mm，ref（ Chevy 5.7 行程 3.48 in ≈ 88.4 mm，吻合） |
| 连杆长 L | 145 | code（≈5.71 in，guess 与真实值接近） |
| 压缩比 cr | 10.2 | code（guess；真实小缸体 9-11.5） |
| 缸数/夹角 | 8 / 90° | code + ref |
| 点火间隔 | 90° 曲轴角 | code（8 缸四冲程 720/8=90，手算一致） |
| 点火顺序 | 1-8-4-3-6-5-7-2 | code + ref（雪佛兰小缸体） |
| 气门窗口 | 排气 140-380°、进气 340-580°（点火后曲轴角），升程 10.5 mm | code（guess，与真实凸轮相位量级一致） |
| 缸压峰值 | 48.6 bar（燃烧后 10° 附近） | code 模型实值（check 断言落在 45–62 bar 内）；真实汽油机 40-70 bar，量级正确 |
| 曲柄销相位 | 45°/135°/-45°/225°（十字曲轴） | code |
| 影片转速 | 700 → 2400 rpm @ t=12.1 s | code（SCRIPT） |
| 回放速度 | 1/20（700 rpm → 屏上 210°/s） | code |

手算检验：行程 = 2×44.5 = 89.0 mm；缸压峰值以 check.mjs 实测 48.6 bar 为准（多方压缩 + 快速燃烧模型，
处于真实汽油机 40-70 bar 区间）；点火间隔 720°/8 = 90°。✓

## 5. 本版改动（相对 teardown 原版）

1. 配色：红色强调 #d6182b → 钴蓝 #1e5fd6；做功燃烧 #ff6a1f → 青 #12aecb；bronze/ceramic → 浅紫/冷白；
   影棚灰 → 浅蓝灰。结构、机构、节拍完全不动。
2. 界面全部汉化（标题、面板、按钮、图例、标注、巡览字幕），单位与公式保留。
