## 4. 唯一输入：曲轴角 θ

- 一切机械姿态与读数都是 **θ（度，可连续累积）** 的纯函数；`model.js` 内部自行折叠（`norm720` / `norm360`），外部可传 −1、5000 等任意值。
- 屏幕刷新时：互动页 `dθ = rpm / 60 × 360 × dt × (1/20)`（`advanceTheta`）；影片页用预积分表 `thetaAt(t)`。
- 影片 θ 初值 12°，`dt = 1/240` 中点法积分（与上游一致），26 s 结束 θ ≈ 12204°（16.95 个四冲程循环）。
- 四冲程相位 ψ = (θ − 点火相位 FIRE[cyl]) mod 720：0 = 压缩上止点 / 点火；180 = 下止点；360 = 进气上止点；540 = 进气下止点。

## 5. 运动学公式（model.js 唯一实现）

坐标：曲轴轴线沿 z（前端 +z、后端 −z），y 向上，x 向右；长度 mm。

1. **曲柄销角**：`a = θ + PIN_PHASE[throwNo]`（度，正视顺时针）；位置 `(x, y) = (r·sin a, r·cos a)`。
2. **活塞位移**（ψ = 该缸相位）：
   `disp(ψ) = r(1 − cos ψ) + (L − √(L² − r² sin²ψ))`，mm（自上止点向下）；行程 = 2r = 89 mm。
3. **活塞速度**：`d(disp)/dψ = r·sinψ·(1 + r·cosψ / √(L² − r² sin²ψ))`，mm/rad；
   ψ=90° 时 = 44.5 × π/180 = 0.7767 mm/°；上/下止点为 0。
4. **连杆角**：`sin β = (r/L)·sin ψ`；ψ=90° 时 β = asin(44.5/145) = 17.872°；同一曲柄销两列符号相反。
5. **活塞销矩离**：`s = r·cosψ + √(L² − r²sin²ψ)`；上止点 189.5、下止点 100.5 mm。
6. **凸轮轴**：`camAngle(θ) = θ/2`；桃形峰值相位 = FIRE[cyl] + 气门窗口中点（排气 260°、进气 460°），桃形角位置 = 峰值相位 / 2。
7. **气门升程**：窗口 `[a,b]` 内 `10.5 · sin²(π·(ψ−a)/(b−a))`，窗口外 0；排气 [140,380]、进气 [340,580]；重叠 340–380°。
8. **冲程判定**：`floor(ψ/180)` → 做功 / 排气 / 进气 / 压缩（0/1/2/3）。
9. **点火**：FIRE 表每 90° 一台缸：1→0°、8→90°、4→180°、3→270°、6→360°、5→450°、7→540°、2→630°；
   `firingNow(θ)` = ψ 最小（刚点火）的气缸。
10. **校验**：`check.mjs` 用曲柄销投影独立复算活塞位置，与解析式最大误差 1.85e-13 mm；速度解析式与数值微分误差 5.2e-10。

## 6. 缸压与气场模型

**容积**（以余隙容积 VC 为单位）：`V(ψ) = 1 + (cr − 1)·disp(ψ)/89`；上止点 1、下止点 10.2。

**缸内压力**（bar，分段）：

| 相位 ψ | 冲程 | 压力 |
|---|---|---|
| 360–540° | 进气 | 0.9 |
| 180–360° | 排气 | 1.1 + 0.4·max(0, 1 − (ψ−180)/40)：打开瞬间 1.5 → 1.1 bar |
| 540–720° | 压缩 | 0.95·(cr / V)^1.32（多方压缩，终了 ≈ 20.38 bar） |
| 0–180° | 做功 | 压缩值 + 前 10° 快速燃烧：`comp + (burn − comp)·k²(3−2k)`，`burn = 54·(1/V)^1.28` |

- 峰值 **48.6 bar @ ψ = 9.45°**（check 实测），落在真实汽油机 40–70 bar 区间。
- 曲线在 720°→0° 首尾连续（20.38 bar），进气/压缩交界 0.9 → 0.95 bar 小台阶为模型口径（照原作）。
- **气场颜色键**（12 s 后作用于玻璃缸套内气体柱）：0 进气·混合气（ψ 360–540）、1 压缩（540–720）、2 做功燃烧（0–60）、3 排气（60–360）。
- **示功图采样**：`pvLoopSamples(cyl, step)` → {ψ, V×VC, bar}，0–720°；**气门正时采样**：`valveTimingSamples(step)` → {ψ, 活塞 %, 进/排升程}。

## 8. 相机与 26 s 巡览

### 8.1 镜头定义（世界单位：1 = 1 m；引擎 mm × 0.001；相机 FOV 26°）

机位参数：`{tx,ty,tz, az(方位角°), el(仰角°), d(距离 m), sx,sy(屏幕偏移 px，1600 版口径 ×1.2)}`。

| 镜头 | 参数（u = 进入该镜头后的秒数） | 用途 |
|---|---|---|
| open（主机位环绕推进） | k = smoother(u/4.1)；tx 0、ty 0.11、tz −0.02；az 4+54k；el 18+9k；d 2.2−0.25k；sx −50·1.2、sy 10·1.2 | 开场 3.5 s 环绕 + 推进 |
| hero（主机位） | az 46+5u；el 26；d 1.95；其余同 open | 主机位 |
| cyl（单缸特写） | 目标 = 缸中心（bankXY(列, 0, 170) × 0.72，y+0.02，z=缸 z）；az = 左列 16 / 右列 −16，再 ±5.5u；el 9+1.2u；d 1.18；sx −48、sy 16.8 | 气缸 1 / 6 特写（隔离） |
| valley（气门室俯视） | tx 0、ty 0.14、tz 0；az 14+7u；el 60；d 2.35；sx −48、sy −33.6 | 俯看气门室 |
| side（侧面） | tx 0、ty 0.1、tz 0；az 100−5u；el 12+1.5u；d 1.95；sx −48、sy 12 | 侧面 |
| front（正面） | tx 0、ty 0.12、tz 0；az −6+5u；el 10+2u；d 1.8；sx −48、sy 12 | 正面 |

- 镜头切换：1.6 s 五次平滑过渡；方位角走最短路径；大幅摆角时距离额外 +0.6·sin(πk) 后撤（避免穿模）。
- 跟踪缸切换（6.9 s / 22.5 s）：单缸特写机位 1.8 s 平滑滑到新缸。
- 单缸隔离：进入 cyl 镜头 1.25 s 后开启；离开后 0.6 s 关闭。
- 曲轴旋转：正视顺时针（`crank` 绕 z 轴 −θ 弧度），凸轮轴 −θ/2，惰轮 +θ·24/72。
