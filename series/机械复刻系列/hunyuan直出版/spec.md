## 4. 界面（用户要求：全中文 + 宝石蓝）

- 设计画布 1920×1080，所有标签 ≥ 34 px（方法论硬规则 5）。
- 强调色：主 `#0F52BA`、亮 `#4A86E8`、深 `#0A357A`、浅 `#BFD7FA`；状态正常用绿色胶囊，不引入第二强调色。
- **信息架构为本版独立设计**：顶部状态条（型号 / 10 拍刻度 / 时间码 / 状态）、左侧竖列仪表（喷射压力表 + 电源）、右侧环形罗盘与 8 臂负载雷达 + 子系统、底部贯穿式节拍大字与操作时间轴。刻意不采用原作/DeepSeek 版的左右白底卡片阵列，以便在并排对比中一眼区分独立实现。
- 六个组成部分齐备：机器、模型、面板、按钮（装配体 / 显示 / 巡览）、窗口（3D 引线标注）、巡览（自动播放，交互接管）。
- 每个数字都来自 `model.js` 的 `stateAt(t)`，与几何同一来源。

## 5. 影棚与相机

- 单位米，Y 轴向上，机器原点贴地，正面朝 +Z；透视相机 3/4 视角（方法论硬规则 5）。
- 冷白蓝浅色影棚、程序化地面刻度与接触阴影；近白机体配深色描边/略深地面提升对比。
- 机器占画面 60–70%；PMREM 环境光 + 主光 / 补光 / 轮廓光 / 反弹光。

### 5.1 运镜（第二版修订）

初版用 `eye/look` 线性插值，换位时直线穿过机器（14.0 s 出现贴脸特写），且每拍前 55% 相机完全静止，
实测 61.5% 的帧位移为零、峰值 0.568 m/帧。修订为：

| 项 | 做法 |
|---|---|
| 机位表示 | 球坐标 `{az, polar, d, target, fov}`，插值时相机沿球面绕行，永不穿过注视点 |
| 方位角 | 走最短弧 `((Δ+540) mod 360)-180`；虹吸机位改到右后方 az 112°，避免与前后机位形成 180° 对穿 |
| 缓动 | 五次 `smootherstep`（C2 连续，速度与加速度都不断），单层，不再套两层缓动 |
| 过渡窗口 | 铺满整个拍间隔，只留 0.22 s 稳定窗口 → 任何时刻都在动 |
| 微漂移 | 叠加 2.1°/s 方位慢摆 + 0.9° 极角摆 + 1.8% 距离呼吸，保证零静止帧 |
| 限速 | 逐帧断言单帧位移 ≤ 0.10 m（实测峰值 0.093 m @ 13.53 s） |
| 防穿模 | 逐帧断言相机到机器中心 ≥ 0.62 m（实测最小 1.38 m）、到注视点 ≥ 0.9 m（实测 1.28 m） |
| 构图 | 按安全区反算 `d`：影片页全屏（机器 62–68%），互动页 ×1.38 给左右面板让位 |
| 影片页 HUD | 分层淡出：面板 0.28、顶条 0.72、底条 0.60、引线 0.55，把画面让给 3D；互动页保持完整 |

## 6. 工程约束

- three.js 0.186.x + esbuild 打包成单个 HTML，字体与贴图内联，运行时零网络请求。
- `render(t)` 纯函数：同一 `t` 永远同一帧；状态量在加载时预计算成 typed arrays。
- `check.mjs` 手算结构量与物理量做断言；`build.mjs` 产出互动页 / 影片页；`capture.mjs` 逐帧录制。
- 页面 < 1 MB，集成 GPU 有降级档位（降低 pixelRatio / 阴影尺寸）。
