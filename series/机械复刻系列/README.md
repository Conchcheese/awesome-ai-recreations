# 机械复刻系列

围绕机械案例的原始参考和目标要求，由不同智能体、AI 模型与工具尝试实现，观察结构、动作、交互和视觉效果，研究更精细、稳定的演示制作方法。

当前有 **9 个案例、14 个实现、5 个署名版本**。每个实现提供可离线运行的互动页与自动巡览页。历史版本存在改编、衍生和记录差异，比较时先核对输入与复用范围。

## 选择版本

| 版本 ID | 特点 | 实现来源 |
|---|---|---|
| `gpt-6-1-sol` | 暖白影棚、橙色控制台，64 秒动作演示 | 从参考重新编写 |
| `deepseek` | 中文、宝石紫；机械章鱼与 V8 | 独立重写的历史实现 |
| `glm` | 中文、钴蓝；覆盖全部 9 个案例 | V8 / 起落架 / 海滩兽改编自上游 MIT 示例，其余新增 |
| `hy4-direct` | 中文、宝石蓝；腕足细节、HUD 与运镜改编 | 独立重写的历史实现 |
| `hy-derived` | 宝石蓝；重做腕节与近景 | 基于 DeepSeek 改编 |

模型名称沿用案例署名，具体输入、复用和验证边界见各版本记录。

## 使用与复刻

- **重建现有版本：** 先按[快速开始](../../docs/快速开始.md)安装依赖，再使用上表的版本文档。
- **让 Agent 复刻：** 发给它 `https://github.com/topmindspace/awesome-ai-recreations`，说「复刻机械章鱼」或其他案例名即可；它会按 [AGENTS.md](../../AGENTS.md) 自动定位[任务书](docs/README.md#开始复刻)与参考。
- **增加案例或版本：** 见[贡献指南](../../CONTRIBUTING.md)。

从仓库根目录查询准确文件与命令：

```bash
python3 scripts/catalog.py show oc8 --variant hy4-direct
python3 scripts/catalog.py show v8 --variant glm
```
