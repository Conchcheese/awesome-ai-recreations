# 海滩兽 Strandbeest SB-10 — 造型规格

来源：teardown 示例 `strandbeest-*`（复刻基底），参考图 `strandbeest-参考-Theo-Jansen与海滩兽.jpg`
（Theo Jansen 与 Strandbeest，Wikimedia Commons）。参数以 Theo Jansen 1990 年的连杆数据为真值。
数字标注：`code`（jansen.js/beast.js 实值）| `ref`（Jansen 公开数据）| `guess`（估算）。

## 1. 部件清单

| 部件 | 数量 | 形状 | 来源 |
|---|---|---|---|
| 腿（詹森连杆） | 20（10 站 × 左右镜像） | 每腿 11 杆，PVC 管材，圆交点精确解算 | code + ref |
| 曲轴 | 1 根 10 个曲柄 | 相位沿轴从头到尾每站差 36° | code + ref |
| 帆 | 10 | 白帆挂在轴上，风力推动 | code |
| 机翼/骨架 | 若干 | 白管三角桁架 | code |
| 橡胶脚 | 20 | 脚垫半高 2.2 单位 | code |

## 2. 唯一输入

风（m/s）。曲轴转速 rps = 0.42·(w/6)^0.75（code），曲轴角 θ(t) 由风速闭式积分，机身位置由
「脚不滑移」条件积分（beast.js MOTION）。一切姿态、读数都是 θ 的函数。

## 3. 关键数字

| 参数 | 值 | 来源 |
|---|---|---|
| 十一个神圣数字 | a38 b41.5 c39.3 d40.1 e55.8 f39.4 g36.7 h65.7 i49 j50 k61.9 l7.8 m15 | ref（Jansen 1990） |
| 腿数 | 20 | ref |
| 相位步进 | 36° | ref（10 站） |
| 比例尺 S | 0.012 m/单位（≈cm） | code |
| 站位跨距 | 9 × 26 × S ≈ 2.81 m；整机 3.1 m | code + console |
| 步幅（支撑段脚位移） | 624 mm（阈值 0.6，模型计算；原 console 写死 672 mm 已改为读模型） | code |
| 支撑相窗口 | 137.5°（阈值 0.6；经典文献 155° 对应更宽的脚垫判定） | code |
| 抬脚高度 | 269 mm（FOOT_MAX−FOOT_MIN = 22.5 单位） | code |
| 机身每转前进量 | 1.632 m（无滑移积分，film speed = rps·\|STRIDE\|·S） | code |
| 风速区间（影片） | 6 → 12.5 m/s @ 10.6 s | code（本版重定时） |

## 4. 影片节拍（timeline.json，本版压缩到 25 s）

13.7 侧面 → 17.1 顶部（脚印）→ 21.0 收回主机位。
