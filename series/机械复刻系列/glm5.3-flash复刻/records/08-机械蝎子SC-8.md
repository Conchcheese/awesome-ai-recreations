# 机械蝎子 Telson SC-8 · 复刻 README

> 复刻模型：**GLM 5.3-Flash**｜方法论：teardown 逐帧模拟器

teardown 方法第 8 台机器：八足 + 双钳 + 毒尾的桌面机械蝎，离线单文件互动页 + 25 秒 1080p60 成片，全中文界面、蓝色系。

## 模型

- **名称**：机械蝎子 Telson SC-8（桌面尺度全长 0.50 m，质量 ≈ 2.1 kg）
- **唯一输入**：动作相位 p ∈ [0,1)，周期 CYCLE = 2.2 s；子相位区间 **行走 0–0.62 / 警戒 0.62–0.72 / 攻击 0.72–1**（写在 model.js，控制台「运行模式」大字实时显示 行走/警戒/攻击）
- **机构**：8 足（4 对，基节偏航 + 股/胫 2 连杆闭式 IK，两足组 A/B 相位差 0.5，占空比 0.5）；2 钳（静息 16±6°，警戒 +28°，攻击 +14° 至上限 58°，0.875–0.895 咬合到 4°）；尾节链 5 节 + 毒针（警戒再拱 6°，攻击段整链刚性前甩 88°，甩窗 0.24 s）；背甲 5 板 + 腹板 5 板 + 传感头双镜头
- **手算基准**：ω峰 = 1.5·Ψ/T = 1.5×88°/0.24 s = 9.61 rad/s，R(静息针尖-尾基) = 0.190 m → **毒针尖端速度峰值 1.830 m/s**（模型解析读数与数值 FK 微分差 0.1%）；钳咬合 1.5×50°/0.044 s × 指长 0.052 → **1.547 m/s**

## 验证结果

- `node glm5.3-flash复刻/src/kit/sims/scorpion-shared/check.mjs`：**19 条断言全部通过**——支撑相足端 y=0（回代 4e-17）；两足组相位差 0.5；IK→FK 闭合 5.9e-17；全程不超伸 121.5 < 184.3 mm；尾节角限位内；攻击段尾尖速度峰 数值 1.832 vs 手算 1.830 m/s（±8%）；毒针全程不触地（min y 98 mm）；钳开口上限/咬合 4.0°；钳指速度峰 1.547 = 手算；行走-攻击边界连续（worst 7.5e-8）；警戒/攻击 8 足全支撑、行走恒 4 足；功耗 12.0–31.5 W；相位驻停 0.66
- 录制 GPU：`ANGLE Metal`（非软件渲染）
- ffprobe：`1920,1080,60/1,25.000000`；音轨 `aac,48000,25.000000`；blackdetect（d=0.1, pix_th=0.05）**无黑场**
- 配乐：55 声，−14.0 LUFS，真峰值 −2.2 dBFS；脚步 thud 时刻由 model.js 同款步态映射（CYCLE/WALK_END/STEPS/PHASE0）在 Python 里逐帧复算，与画面不漂移
- 静帧自查四轮（详见下），每轮 beats 接触表 + 拍中段帧 + 转场 0.25 s 抽帧逐格过

## 问题与改法

1. **钳零件被拉成 1 米长管 / 尾节消失**：`place()` 帮手函数被少参调用，`scale.set(undefined,…)` 产生 NaN 矩阵（另有手掌一段多余的 `scale.set(1,1,1)` 覆盖了拉伸）。改法：三处 place 统一为「半径烘进几何、scale 只管长度」的 `(1, len, 1)`。
2. **机器太「蜘蛛」**：管件太细、球关节过大、支撑太远。改法：股/胫/基节加粗约 40%、膝/髋球收敛、FOOT_OUT 收 18%、足垫加大。
3. **钳拖地、读作杂物**：钳肩 y 0.02 → 0.05，静息抬 10°，掌/基段比例收敛，铰链环缩小，静息开口 12°→16°。
4. **尾链拆解偏移过大**：0.055×(i+1) 最大 0.275 m（半台机器），改 0.016×(i+1)。
5. **隔离失效**：`isolate()` 的桶名与 key 判断写重，隔离「腿 R2」时九条腿全实心。改法：右钳与其余七腿永远只做 ghost 桶。
6. **模式大字与模型不符**：行走拍里周期性进入攻击段时，大字仍显示拍名「行走」。改法：`MODE_NAME[modeOf(p)]` 实时模式，拍名退到状态/阶段行。
7. **钳速度曲线、步态图数据**：全部由 model 解析式/逐帧采样算出（352 格步态图、41 点钳速曲线），无一处写死数字。
8. **相位起点**：pAt 加 PHASE0=0.35，第 0 帧即处于步行中（缩略图完整机器着地），收尾拍相位减速驻停警戒带中点 0.66，配乐同式复刻。

## 复现

```bash
node glm5.3-flash复刻/src/kit/sims/scorpion-shared/check.mjs
node glm5.3-flash复刻/src/kit/sims/build.mjs scorpion-film && node glm5.3-flash复刻/src/kit/sims/build.mjs scorpion-live
node glm5.3-flash复刻/src/kit/sims/capture.mjs scorpion-film --size 1600x900 --dpr 1.2 --stills beats --cols 4 --out teardown-out/scorpion-beats.png
node glm5.3-flash复刻/src/kit/sims/capture.mjs scorpion-film --size 1600x900 --dpr 1.2 --out teardown-out/scorpion-silent.mp4
python3 run_sfx.py glm5.3-flash复刻/src/kit/sims/scorpion-shared/score.py
ffmpeg -y -i teardown-out/scorpion-silent.mp4 -i teardown-out/scorpion-score.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart teardown-out/scorpion-final.mp4
```

## 未尽事项

- 步态图触地连线在警戒段（8 足全支撑）时呈现为环绕多边形，步行段为四边形——两种形态都真实，但未做 strandbeest 式的连续足迹拖尾（时间盒外）。
- 钳特写拍的自然攻击咬合（10.4 s 附近）与演示包络叠加，极端帧动指会与不动指轻微交叠（0.5 mm 级），未单独调参。
- 互动页在集成 GPU 上会自动降画质档位（实测无头环境降到 tier 1），桌面独显应保持 tier 0。
