## 复现

Node.js 20+。以下从**本目录**执行，以 V8 为例：

```bash
cd src/kit
npm ci
npx playwright install chromium
node sims/build.mjs v8-film v8-live
node sims/v8-shared/check.mjs
```

构建产物位于 `src/kit/teardown-out/dist/`，不会自动覆盖 `pages/`。其他案例的准确命令可从仓库根目录查询：

```bash
python3 scripts/catalog.py show jellyfish --variant glm
```

### 导出视频

另需 Python 3.10+、FFmpeg / ffprobe。在 `src/kit/` 执行：

```bash
node sims/capture.mjs v8-film --size 1600x900 --dpr 1.2 --out teardown-out/v8-silent.mp4
python3 run_sfx.py sims/v8-shared/score.py
ffmpeg -y -i teardown-out/v8-silent.mp4 -i teardown-out/v8-score.wav \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart \
  teardown-out/v8-final.mp4
```
